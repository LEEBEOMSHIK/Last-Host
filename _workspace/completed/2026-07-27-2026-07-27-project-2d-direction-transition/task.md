# 작업: 프로젝트 2D 아이소메트릭 방향 전환

- 상태: 완료 — QA `PASS`, 프로젝트 총괄 `내부 승인 가능`

## 목적

사용자 승인에 따라 `마지막 숙주 / The Last Host`의 확정 비주얼·공간 표현을 기존 도트풍 하이브리드 2.5D에서 목업 기반 순수 2D 아이소메트릭 도트 방식으로 전환한다.

## 사용자 요청

- 생성한 2D 하수도 게임플레이 목업을 별도 reference 폴더에 보관한다.
- 프로젝트 전역의 현재 방향 문서를 2D 기준으로 갱신한다.
- 이미지가 필요할 때 ChatGPT 내장 이미지 생성과 연계할 수 있는 절차를 문서화한다.
- 기존 역할과 중복되지 않는다면 ChatGPT 이미지 연계 전담 에이전트를 추가한다.

## 승인된 방향

- Unity 엔진과 PC 우선 목표는 유지한다.
- 쥐 숙주 핵심 루프, 면역 경계도, 내부 미니게임, 변이 선택 구조는 유지한다.
- 환경·캐릭터·효과는 2D 아이소메트릭/쿼터뷰 도트 타일과 스프라이트로 제작한다.
- 기존 3D 환경·저폴리 원본·Blender 프리렌더 파이프라인은 신규 제작 기본 경로에서 제외하고 레거시 기록으로 보관한다.
- 목업은 목표 품질 reference이며 즉시 사용 가능한 타일셋·스프라이트 시트가 아니다.

## 산출물

- `docs/design/visual/references/` 목업과 README
- 기획·프로토타입·프로젝트·Unity·시각 기준 문서의 2D 전환 반영
- ChatGPT 이미지 생성/선별/출처/저장/QA 워크플로
- ChatGPT 이미지 아트 에이전트 역할 문서와 에이전트 색인
- 갱신된 프로젝트 스킬·현황판·인수인계

## 금지 범위

- 이번 작업에서 Unity 씬·코드·ProjectSettings·패키지 변경
- 생성 목업을 실제 타일셋이나 최종 플레이어블 에셋으로 선언
- 기존 2.5D/Blender 이력 삭제
- 인간·병원·연구소·백신·엔딩 등 프로토타입 범위 확대

## 완료 기준

- 현재형 기준 문서에서 2.5D와 2D 방향이 충돌하지 않는다.
- 목업 reference의 용도·한계·출처가 기록된다.
- ChatGPT 이미지 생성은 내장 imagegen 우선, 작업 패킷 기록, 사람 선별, 최종 게임 에셋 재제작·QA라는 경계를 가진다.
- QA/검증 에이전트 대조와 프로젝트 총괄 내부 승인 판정이 있다.
