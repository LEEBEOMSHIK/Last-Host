# 프로젝트 총괄 관리자 검토

## V2 최종 재검토 — 현재 유효 판정

### 판정

`내부 승인 가능 — 환경·쥐 V2·HUD 통합 제작 기준 후보의 사용자 확인 대기`

이 판정은 세 이미지를 수작업 시험 재제작의 시각 reference로
사용할 수 있다는 의미다. 최종 타일셋, 투명 방향 스프라이트,
애니메이션, 전체 8방향, 구현 HUD 또는 Unity 반입을 승인하지 않는다.

### V1 수정 조건 해소 확인

| 이전 수정 조건 | V2 판정 | 총괄 직접 확인 |
| --- | --- | --- |
| 뒤쪽 쿼터 둔부 폭·원형 체적 축소 | 해소 | V1의 거의 원형인 둔부가 좁아지고 골반–어깨–목으로 이어지는 긴 타원 축과 허리 테이퍼가 보인다. |
| 긴 몸통 축·자연형 등–목–머리 곡선 | 해소 | 측면의 긴 자연형 체형이 유지됐고 뒤쪽 뷰도 머리까지 이어지는 몸통 방향이 명확하다. |
| 세 방향 질량·화면 점유율 | 시각 조건 해소 | 뒤쪽 질량이 같은 개체의 쿼터뷰 단축 원근으로 허용할 범위에 들어왔다. 정확한 bbox와 픽셀 수치는 후속 수작업 조건이다. |

V1 반려본과 V2 교정본을 직접 비교했다. V2의 뒤쪽 쿼터는 더 이상
별도의 둥근 체형처럼 보이지 않으며, V1 총괄 수정 조건은 제작 방향을
막지 않을 수준으로 해소됐다.

### 후속 수작업 조건

- 공통 몸통 bbox, 투명 캔버스, 발 접지 피벗과 실제 플레이 크기
  점유율은 대표 3방향 정지·2프레임 시험 시트에서 수치로 고정한다.
- 환경은 반복 이음·명도·바닥 노이즈를 시험 타일에서 검증한다.
- HUD는 초상 크기, 투명 모듈, 빈·부분·가득 참 상태와 외곽 대비를
  시험한다.
- 쥐 전체 8방향·완성 보행과 Unity Sprite·Tile·UI Import는
  별도 사용자 승인과 QA 전까지 진행하지 않는다.

## V1 최초 판정 이력

`수정 필요`

환경과 HUD 통합본은 보완 조건을 붙여 사용자 확인용 제작 방향
reference로 제시할 수 있다. 그러나 쥐 통합본의 뒤쪽 쿼터는 측면·
앞쪽 쿼터와 같은 개체의 회전으로 보기 어려울 정도로 둔부 폭,
몸통 질량과 화면 점유율이 달라 `대표 3시점 통합 제작 기준`의 핵심
목적을 충족하지 못한다.

현재 쥐 PNG를 측면·앞쪽 쿼터의 부분 reference로 설명할 수는 있지만,
세 방향 공통 비례 기준이나 후속 수작업 재제작의 마스터 시트로
승격하면 안 된다.

## 근거

- 사용자 승인은 환경·쥐·HUD 통합 기준 이미지 각 1개와 시험
  재제작 브리프까지이며, 실제 출력과 로그는 승인 수량 `3개`에
  맞는다.
- 환경은 V2의 모듈·경로 구조와 V1의 갈색 팔레트·황동 조명을
  함께 반영했다. 낮은 명도·바닥 노이즈·반복 이음은 후속 수작업
  시험에서 해결할 조건으로 분리할 수 있다.
- HUD는 V2의 좌측 초상·우측 게이지 구조와 V1의 따뜻한 재질을
  반영했다. 큰 초상·검은 내부 의존·투명 상태 규격은 후속 시험
  조건으로 분리할 수 있다.
- 쥐 측면과 앞쪽 쿼터는 자연형 체형과 털 군집 단순화 방향을
  반영했지만, 뒤쪽 쿼터는 둔부가 거의 원형으로 닫히며 몸통의
  긴 축과 허리 테이퍼가 사라졌다. 실제 PNG를 직접 확인한 결과
  비주얼/테크아트와 QA의 `뒤쪽 쿼터 수정 필요` 판정이 타당하다.
- 시험 브리프는 측면·앞쪽·뒤쪽 쿼터가 같은 캔버스·피벗·체형·
  화면 점유율을 사용해야 한다고 정의한다. 현재 쥐 통합본은 이
  일관성 기준을 시각적으로 지지하지 못한다.

## 문제 사안

- 문제: 쥐 뒤쪽 쿼터가 측면·앞쪽 쿼터와 다른 체형 질량으로 보인다.
- 영향: 이 이미지를 3방향 마스터 기준으로 사용하면 이후 8방향과
  보행에서 몸통 크기·피벗·화면 점유율 불일치가 확대된다.
- 추천: 쥐 통합본만 교정한 뒤 재검토하고, 환경·HUD는 현재 조건부
  reference를 유지한다.
