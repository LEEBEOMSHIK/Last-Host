# 인계

## 현재 상태

사용자가 환경·쥐 V2·HUD 통합 기준 세 이미지를 모두 수용했다.
비주얼/테크아트, 독립 QA와 총괄 재검토도 완료됐다.

현재 QA 판정은
`조건부 사용 가능 — V2를 대표 3방향 수작업 제작 기준 reference로 사용할 수 있음`이다.

총괄 재판정은
`내부 승인 가능 — 환경·쥐 V2·HUD 통합 제작 기준 후보의 사용자 확인 대기`다.

## 다음 순서

1. 실제 반복 타일·대표 3방향 쥐·투명 HUD 모듈의 시험 재제작
   착수를 별도 승인받는다.
2. 실제 재제작에서는 공통 bbox·투명 캔버스·발 피벗을 첫 캐릭터
   기술 게이트로 고정한다.
3. 시험 결과를 수용한 뒤에만 8방향·보행과 Unity 반입을 승인한다.

## 보호 경계

- UnityProject와 기존 Stage2·Stage3 변경을 수정하지 않는다.
- `APP_UI_EDITOR_ONLY`, `_workspace/previews/`를 보존한다.
- 최종 게임 에셋·8방향·Unity 반입으로 확대하지 않는다.
- 환경·HUD의 조건부 보완과 쥐 공통 bbox·피벗·점유율 수치 정합을
  실제 시험 재제작 브리프에서 유지한다.
- 통합 PNG는 불투명 제작 방향 보드이며 그대로 잘라 게임 에셋으로
  사용하지 않는다.
- V2의 공통 몸통 bbox·투명 캔버스·발 접지 피벗은 실제 수작업
  3방향 시트에서 수치로 고정한다.
- 반려 V1은 `artifacts/rejected/rat-integrated-target-v1.png`에
  이력으로 보존하고 사용자 확인 묶음에는 포함하지 않는다.
