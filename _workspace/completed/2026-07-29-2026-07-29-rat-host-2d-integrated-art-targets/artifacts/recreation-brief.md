# 실제 게임 규격 시험 재제작 브리프

## 문서 상태

이 문서는 통합 제작 기준 이미지를 실제 타일·스프라이트·UI로 옮길
첫 시험 범위를 정한다. 아래 수치는 비교를 위한 시험값이며 최종
프로젝트 규격이 아니다.

## 공통 시험값

- 내부 화면: `960×540`
- 아이소메트릭 바닥 셀: `64×32 px`
- 시험 PPU: `64`
- 필터: Point
- 밉맵: 비활성
- 월드와 HUD는 서로 분리해 가독성을 확인

최종 확정 전에는 기존 기술 샘플 값을 재사용하되, 화면 점유율과
픽셀 밀도 비교 결과에 따라 조정할 수 있다.

## 환경 시험 묶음

- 깨끗한 바닥 1종과 마모 변형 1종
- 벽 상단·정면·모서리 대표 모듈
- 물 중앙·경계 대표 모듈
- 통, 상자, 배수구 각 1종
- 작은 방 1개를 조립해 타일 경계, 경로 판독, 소품 깊이 정렬을 확인

필수 검증은 반복 경계, 벽돌 줄눈 연결, 물 가장자리 연결,
장식 노이즈가 이동 경로보다 앞서 읽히지 않는지다.

## 쥐 시험 묶음

- 대표 방향: 측면, 앞쪽 쿼터, 뒤쪽 쿼터
- 상태: 정지와 짧은 2프레임 보행 시험
- 모든 셀은 같은 캔버스와 발 접지 피벗 사용
- 몸통 길이, 등 곡선, 귀 크기, 눈 크기, 주둥이, 꼬리 길이와
  화면 점유율을 고정

2프레임은 체형·접지 안정성을 빠르게 확인하기 위한 시험값이다.
최종 보행 프레임 수와 전체 8방향은 이 시험 후 별도 승인한다.

## HUD 시험 묶음

- 쥐 초상 프레임
- 붉은 숙주 생명력 프레임과 채움
- 청록 면역 경계도 프레임과 채움
- 실제 재제작 파일은 독립 투명 모듈을 목표로 하며 숫자·문자는
  이번 시험에서 제외

## 이번 작업에서 하지 않는 것

- 실제 타일·스프라이트·UI PNG 제작
- 투명 영역, 9-slice, 최종 피벗·애니메이션 규격 확정
- Unity Import, 씬 배치, Play·빌드 검증
- 쥐 전체 8방향과 완성 보행 제작

## 후속 승인 순서

1. 사용자가 통합 제작 기준 이미지 3개를 확인한다.
2. 위 시험 묶음의 실제 게임 규격 재제작 착수를 승인한다.
3. 시험 에셋의 반복·접지·가독성 QA 뒤 전체 8방향·보행 범위를
   승인한다.
4. Unity 반입은 별도 작업 패킷에서 Import·Play·Windows 빌드를
   검증한다.
