# 첫 2D 아트 후보 비주얼 검토

## 검토 범위와 판정 상태

- 검토 대상: 환경·소품 2안, 쥐 대표 3방향 2안, 최소 HUD 2안
- 비교 기준:
  `rat-host-2d-isometric-gameplay-mockup-v1.png`,
  `rat-concept-a-natural.png`, 2D 아이소메트릭 도트 스타일 규칙
- 검토 방식: 목표 reference 2개와 후보 PNG 6개를 원본 해상도로 직접
  열고 생성 로그의 프롬프트·1차 점검과 독립적으로 비교
- 현재 판정: 6개 모두 사용자 선별 전 `미선별 이미지 후보`

## 비주얼 판단

단일 후보를 그대로 실제 에셋으로 채택하기보다 각 묶음에서 구조와
분위기의 장점을 분리해 수작업 재제작 기준으로 조합하는 편이 적합하다.

- 환경: `ENV-V2 구조·경로 판독 + ENV-V1 팔레트·황동 조명`
- 쥐: `RAT-V1 자연형 체형·실루엣 + 더 적고 큰 털 픽셀 군집`
- HUD: `HUD-V2 배치·대비·모듈 구조 + HUD-V1 따뜻한 금속·석재 재질`

이 조합은 사용자 선별 전 제작 기준 추천이며, 어느 PNG도 최종 타일,
스프라이트 시트나 구현 UI로 승인한다는 뜻이 아니다.

## 환경·소품 후보 비교

| 기준 | ENV-V1 | ENV-V2 |
| --- | --- | --- |
| 목표 reference 근접성 | 따뜻한 갈색 벽돌, 황동 램프와 청록 수로가 목표 목업의 분위기·명암 깊이에 더 가깝다. | 고정 아이소메트릭 하수도 구조는 맞지만 차콜·청록 비중이 커서 목표보다 차갑고 어둡다. |
| 게임플레이 가독성 | 조립 방의 중앙 길은 읽히지만 바닥 균열·오염·벽돌 하이라이트가 촘촘해 작은 화면에서 쥐와 경로를 덮을 수 있다. | 넓은 중앙 이동면, 벽·수로·바닥의 명도 단계와 모듈 실루엣이 더 명확하다. |
| 아이소메트릭·픽셀 일관성 | 전체 시점은 일관되지만 조각마다 벽 두께와 세부 밀도가 다르고 표면 노이즈가 많다. | 벽 기둥, 바닥 조각, 수로 경계와 소품의 투시·픽셀 군집이 상대적으로 단순하고 통일되어 있다. |
| 실제 재제작 용이성 | 팔레트·재질·광원 참고에는 좋지만 복잡한 균열과 장식은 반복 타일로 정리할 때 삭제·단순화 작업이 크다. | 기본 바닥·벽·수로·배관·통·상자·배수구를 모듈 목록으로 분해하기 쉽다. |
| 주요 위험 | 표면 노이즈, 장식 과다, 램프가 구운 명암과 Unity 조명을 중복시킬 가능성 | 쥐·수집물 실루엣이 어두운 배경에 묻힐 가능성, 차가운 분위기가 목표 목업에서 이탈 |

### 환경 제작 기준 추천

`ENV-V2`의 중앙 이동면 폭, 벽·수로 경계, 단순한 모듈 형태를 구조
기준으로 삼는다. 여기에 `ENV-V1`의 따뜻한 갈색 벽돌, 제한된 황동
조명, 젖은 회갈색 바닥과 청록 수로의 온도 대비를 적용한다.

재제작 시에는 다음을 제한한다.

- 기본 타일에는 큰 균열·이끼·반사점을 최소화하고 장식 변형으로 분리
- 바닥, 벽, 수로와 소품의 논리 픽셀 크기 통일
- 조명 없는 기본 모듈과 램프 영향을 받는 변형을 분리
- 화분·덩굴·난간·사다리 등 생성 과정의 추가 요소는 자동 포함하지 않음

## 쥐 대표 3방향 후보 비교

| 기준 | RAT-V1 | RAT-V2 |
| --- | --- | --- |
| 목표 reference 근접성 | 긴 몸통과 주둥이, 등–목–머리 곡선, 발·귀·꼬리가 자연형 쥐 reference에 더 가깝다. | 색과 기본 특징은 유지하지만 둥근 몸통·큰 눈·짧아 보이는 주둥이가 자연형보다 귀여운 방향으로 기운다. |
| 게임플레이 가독성 | 실루엣과 방향은 읽히지만 털 결이 너무 촘촘해 실제 축소 시 몸통 경계가 흔들릴 수 있다. | 털 군집이 비교적 단순해 축소 판독은 유리하지만 큰 눈과 둥근 몸통이 캐릭터 인상을 바꾼다. |
| 방향·픽셀 일관성 | 측면은 가장 자연스럽다. 앞쪽은 정면에 가깝고 뒤쪽 몸통이 더 크게 보여 세 방향 점유율이 다르다. | 세 방향 모두 큰 군집을 쓰지만 뒤쪽 몸통이 과도하게 크고 머리가 옆으로 돌아 동일한 방향 각도 기준이 약하다. |
| 실제 재제작 용이성 | 측면 체형을 마스터 실루엣으로 삼기 좋다. 털·수염·발가락을 줄이는 수작업 정리가 필요하다. | 단순화 수준은 참고할 수 있으나 체형·머리·눈을 다시 자연형으로 되돌리는 작업이 필요하다. |
| 주요 위험 | 털 노이즈, 방향별 화면 점유율·접지점 차이, 축소 시 얼굴 세부 붕괴 | 햄스터·봉제 인형 같은 인상, 방향별 체적 변화, 큰 눈이 최종 정체성으로 굳을 가능성 |

### 쥐 제작 기준 추천

`RAT-V1`의 측면 체형과 자연형 reference의 등–목–머리 곡선, 주둥이
길이, 귀·발·긴 꼬리를 마스터 기준으로 삼는다. 단, 털은 `RAT-V2`처럼
더 적고 큰 명암 군집으로 단순화하되 v2의 둥근 몸통과 큰 눈은 따르지
않는다.

8방향 확장 전 다음 일관성 시트가 필요하다.

- 같은 몸통 길이·높이, 머리와 눈 비율, 귀 크기, 꼬리 길이·굵기
- 같은 캔버스와 발 접지 피벗, 화면 점유율
- 측면·앞쪽 쿼터·뒤쪽 쿼터의 명확한 회전 각도
- 정지·보행에서 유지할 큰 명암 덩어리와 삭제할 미세 털 기준

현재 3방향은 실제 보행 프레임이나 8방향 일관성을 입증하지 않는다.

## 최소 HUD 후보 비교

| 기준 | HUD-V1 | HUD-V2 |
| --- | --- | --- |
| 목표 reference 근접성 | 황동빛 테두리와 따뜻한 돌·금속 재질이 목표 목업 HUD에 더 가깝다. | 차콜 철재와 청록 산화가 하수도에는 맞지만 목표보다 차갑고 공업적이다. |
| 게임플레이 가독성 | 적색·청록 게이지는 분명하나 초상 프레임과 장식 탭, 두꺼운 게이지가 화면을 많이 차지한다. | 초상과 두 게이지의 정렬, 색 대비, 얇은 구조가 기능적으로 더 명확하다. |
| 픽셀·월드 일관성 | 따뜻한 재질은 월드와 어울리지만 초상 세부와 광택 픽셀이 실제 축소 시 복잡할 수 있다. | 픽셀 군집과 모듈 외곽은 단순하지만 검은 내부·외곽 배경이 어두운 월드에서 사라질 수 있다. |
| 실제 재제작 용이성 | 재질 팔레트 참고에는 좋다. 장식 제거, 초상 축소, 게이지 높이 조정이 필요하다. | portrait·bar를 독립 모듈과 9-slice 구조로 분해하기 쉽다. |
| 주요 위험 | HUD 점유율 과다, 초상과 실제 쥐 외형 불일치, 장식이 수치보다 먼저 읽힘 | 검은 배경 의존, 월드 위 외곽 대비 부족, 차가운 재질이 목표 목업에서 이탈 |

### HUD 제작 기준 추천

`HUD-V2`의 좌측 초상·우측 게이지 정렬, 얇은 프레임과 명확한
적색/청록 대비를 구조 기준으로 삼는다. `HUD-V1`의 따뜻하고 낡은
황동·석재 재질을 제한적으로 적용한다.

재제작 시에는 다음을 확인한다.

- 검은 판 전체가 아니라 투명 배경의 초상·게이지 독립 모듈
- v1보다 작은 초상과 낮은 게이지 높이
- 빈 상태·부분 상태·가득 찬 상태의 마스크와 9-slice 가능성
- 밝은 바닥·어두운 벽·청록 수로 위에서 모두 보이는 외곽 대비
- 실제 쥐 마스터 스프라이트와 동일한 외형을 사용한 초상

## 사용자 선별 전 제작 기준 추천

| 묶음 | 추천 기준 | 사용자에게 확인할 핵심 선택 |
| --- | --- | --- |
| 환경 | `V2 구조 + V1 팔레트·따뜻한 황동 조명` | 목표 목업의 따뜻함을 유지하면서 장식 밀도를 줄이는 방향이 맞는가 |
| 쥐 | `V1 자연형 체형 + 털 군집 단순화` | 자연형 실루엣을 우선하고 큰 눈·둥근 몸통을 제한하는가 |
| HUD | `V2 구조·대비 + V1 재질` | 기능적 배치를 유지하면서 따뜻한 하수도 재질로 조정하는가 |

사용자가 각 조합 방향을 수용한 뒤에만 수작업 재제작 브리프를 확정한다.
단일 PNG를 최종안으로 강제 선택할 필요는 없다.

## 목업과 실제 에셋 경계

- 환경 후보는 반복 가능한 Tile asset이 아니며 경계·모서리·변형 규칙,
  충돌, 가림과 정렬 데이터를 새로 만들어야 한다.
- 쥐 후보는 투명 배경, 공통 캔버스·피벗, 보행 프레임 또는 8방향
  일관성이 보장된 스프라이트 시트가 아니다.
- HUD 후보는 투명 모듈, 실제 상태 데이터, 마스크, 9-slice,
  해상도 대응이 구현된 UI가 아니다.
- 6개 PNG의 상태는 사용자 선별 전까지 `미선별`을 유지한다.

## 플레이스홀더 기준

- 선별 전에는 현재 Unity의 기존 플레이스홀더를 유지한다.
- 후보 PNG를 잘라 임시 Sprite·Tile·UI로 반입하지 않는다.
- 실제 반복·투명·피벗 규격을 갖춘 수작업 시험 자산이 승인된 뒤,
  별도 Unity 반입 작업에서 비교한다.

## 승인 필요

1. 환경·쥐·HUD의 조합 재제작 방향에 대한 사용자 선별
2. 실제 반복 타일·소품 수작업 재제작 범위
3. 쥐 대표 방향 시험과 이후 전체 8방향·보행 확장
4. HUD 투명 모듈·상태별 자산 제작
5. Sprite·Tile Import와 Unity 씬 적용

## 검증 방법

- 수작업 환경 시험: 실제 타일 반복과 이음, 이동 경로 대비, 소품
  접지·가림을 확인한다.
- 쥐 시험: 동일 캔버스·피벗에서 대표 3방향 정지·짧은 보행을
  실제 플레이 크기로 축소해 체형과 접지를 확인한다.
- HUD 시험: 실제 게임 화면 위에서 점유율, 밝고 어두운 배경 대비,
  빈/부분/가득 참 상태를 확인한다.
- Unity 반입은 별도 승인 후 Play·Windows 빌드에서 픽셀 떨림,
  방향 전환, 정렬 팝과 가독성을 확인한다.
