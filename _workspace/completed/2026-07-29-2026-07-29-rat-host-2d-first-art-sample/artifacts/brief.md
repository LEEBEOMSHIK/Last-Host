# 공통 이미지 생성 브리프

## 목적

실제 게임 에셋 제작에 들어가기 전에 목표 목업에 가까운 환경·쥐·HUD 방향을 빠르게 비교한다.

## 공통 비주얼

- 2D 아이소메트릭/쿼터뷰 도트 게임
- 실제 픽셀 군집이 보이는 제한 팔레트
- 어두운 갈색 벽돌, 젖은 회갈색 바닥, 탁한 청록 수로
- 따뜻한 황동빛 램프와 제한된 녹색 이끼
- 조밀하지만 이동 경로와 쥐가 먼저 읽히는 화면
- 자연형 갈색 쥐, 과도한 의인화·큰 머리·만화형 비율 금지
- HUD는 월드와 분리되고 작은 실제 화면에서도 읽혀야 함

## 공통 금지

- 3D 렌더, 저폴리 폴리곤 외형, 매끈한 벡터 그래픽
- 특정 게임·작가·브랜드의 고유 디자인 복제
- 사람, 병원, 연구소, 백신, 엔딩 콘텐츠
- 글자, 로고, 워터마크
- 최종 타일셋·최종 스프라이트 시트라고 오해하게 만드는 표기

## 입력 reference 역할

- 목표 게임플레이 목업: 분위기, 아이소메트릭 카메라, 환경 밀도, 명암, HUD 배치
- 자연형 쥐 콘셉트: 체형, 털색, 귀·코·꼬리, 자연스러운 동물 실루엣

## 후보 상태

모든 출력은 `미선별 이미지 후보`다. 반복 타일, 투명 배경, 공통 피벗, 방향별 애니메이션 규격을 보장하지 않으며 사람이 게임 규격으로 재제작해야 한다.
