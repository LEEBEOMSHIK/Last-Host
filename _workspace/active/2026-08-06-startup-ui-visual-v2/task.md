## 공통 비주얼 계약

- 2D 아이소메트릭/쿼터뷰 도트 또는 같은 논리 픽셀 밀도의 타이틀 일러스트, 제한된 갈색·먹색·녹청색 팔레트.
- 게임 전체 정체성인 바이러스의 생존·감염·변이·숙주 이동을 전달한다.
- 특정 숙주가 중심 주인공처럼 보이면 실패다. 쥐가 등장하더라도 벌레·모기·새 등 다른 숙주 흔적과 같은 작은 비중이어야 한다.
- 하수도는 여러 환경 중 하나의 흔적으로만 허용하며 화면 전체 배경으로 고정하지 않는다.
- 배경 자체에는 제목·버튼·HUD·로고·워터마크·임의 글자를 넣지 않는다.
- UI가 올라갈 넓고 비교적 어두운 negative space를 명확히 확보한다.
- 기존 gameplay reference의 분위기와 논리 픽셀 밀도만 참고하고 장면을 복제하지 않는다.
- 인간·병원·연구소·백신·엔딩의 직접 묘사, 제3자 캐릭터·상표·특정 작가 스타일 모사는 금지한다.
- I~K에서는 기본 박테리오파지를 보라·분홍·흰색의 2D 도트 마스코트로 재해석한다. 큰 정이십면체 캡시드, 짧은 몸통, 팔 2개·다리 2개, 작은 꼬리와 둥근 spike 실루엣을 유지한다.
- 추상 입자만으로 전이를 대신하지 않는다. 박테리오파지의 달리기·도약·부유 동작과 이어지는 보라/청록 afterimage가 이동 방향을 보여야 한다.
- 먹이사슬은 도표·화살표·원형 UI가 아니라 먹이 탐색·추격·포식 직전의 자연스러운 장면 행동으로 읽혀야 한다.
