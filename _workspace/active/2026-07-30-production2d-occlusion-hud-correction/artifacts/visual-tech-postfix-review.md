# 수정 후 비주얼/테크아트 재검토

## 검토 범위

- `game-view-occlusion-hud-corrected.png`
- `implementation-sweep-before/` PNG 9장과 CSV
- `implementation-sweep-after/` PNG 9장과 CSV
- `hud-before-after.png`

Unity 구현 파일은 수정하지 않았다. 정지 캡처와 기록된 런타임 수치를 대조했으며, 실제 Game View 포커스의 네이티브 WASD 체감은 사용자 판단으로 남긴다.

## 최종 판정

| 사용자 피드백 | 판정 | 근거 |
| --- | --- | --- |
| HUD 초상 내부 상단의 불필요한 황동 조각 | **PASS** | 수정 후 황동 조각이 완전히 사라졌다. 얼굴·귀·눈·코·털·수염과 알파 윤곽은 전후 동일하고, 실제 Game View에서도 외곽 프레임과 초상이 이중 장식 없이 분리된다. |
| 통·상자·벽을 지날 때 표면 위로 올라탄 듯한 앞뒤 표현 | **정적 계약 PASS / 실제 WASD 사용자 판단** | 수정 후 앞 분리에서는 쥐가 앞, 뒤 분리에서는 쥐가 뒤, 동일 pivot에서는 오브젝트가 정확히 `+1` 앞이다. 확대된 접지 collider가 실제 이동 중 물리 관통을 막는 것도 자체 검증됐다. 다만 단일 쥐 SpriteRenderer 전체가 한 번에 전환되는 체감은 정지 캡처만으로 최종 승인할 수 없다. |

현재 캡처에서 즉시 재수정해야 할 시각 blocker는 발견하지 못했다.

## HUD 상세 검토 — PASS

- `hud-before-after.png`에서 제거된 부분은 초상 상단의 분리된 황동 컴포넌트뿐이다.
- 쥐 얼굴과 털의 픽셀 밀도, 명암, 실루엣, 수염 끝이 유지됐다.
- `game-view-occlusion-hud-corrected.png`에서 초상은 황동 외곽 프레임 안에 정상 배치되고 상단 이중 장식이 보이지 않는다.
- 초상과 외곽 프레임의 색·명암 대비도 기존 품질을 유지한다.

## 오브젝트별 앞·동일·뒤 검토

### 통 — 정적 계약 PASS

- 앞 분리: `rat 104 > barrel 76`. 쥐 몸이 통의 지면부 앞을 가리는 방향이 맞다.
- 동일 pivot: `rat 75 < barrel 76`. 통이 쥐보다 정확히 한 단계 앞이다.
- 뒤 분리: `rat 50 < barrel 76`. 통이 쥐 몸 중앙을 가리며 뒤 통과가 읽힌다.
- collider 폭이 `0.48 → 0.60`, 쥐 폭이 `0.62 → 0.92`로 넓어져 옆으로 과도하게 파고들 수 있는 여지가 줄었다.

### 상자 — 정적 계약 PASS

- 앞 분리: `rat 3 > crate -24`.
- 동일 pivot: `rat -25 < crate -24`.
- 뒤 분리: `rat -52 < crate -24`.
- collider 폭이 `0.55 → 0.70`으로 넓어져 상자 측면과 쥐 몸의 물리 점유 차이가 줄었다.

### 벽 — 정적 계약 PASS

- 앞 분리: `rat -46 > wall -74`.
- 동일 pivot: `rat -75 < wall -74`.
- 뒤 분리: `rat -95 < wall -74`.
- 벽 collider 폭은 이미 시각 지면부와 가까워 유지됐다. 동일 pivot과 뒤 상태에서 벽이 쥐를 가리는 방향이 일관된다.

## 전환선과 접촉 상태

### PASS

- 수정 전 통·상자의 tieBreak `11/12`가 만든 `0.11/0.12 world unit` 전환선 이동이 제거됐다.
- 수정 후 세 오브젝트 모두 tieBreak `1`이며 동일 pivot에서 오브젝트가 쥐보다 정확히 `+1` 앞이다.
- 앞/뒤 분리 표본은 collider 간격 `0.015`, overlap `false`이고 정렬 관계가 모두 올바르다.
- 300회 정지 재계산에서 order 변화가 없어 정지 떨림은 보이지 않는다.

### 사용자 판단

- 동일 pivot 캡처는 collider overlap이 `true`인 강제 배치라 실제 이동으로 도달할 수 없는 진단 상태다. 이 화면에서는 오브젝트가 쥐 몸 중앙을 크게 절단해 보이지만, 그 자체를 플레이 blocker로 판정하지 않는다.
- 앞/뒤 분리 상태도 긴 꼬리와 큰 단일 스프라이트 때문에 시각 실루엣은 계속 겹친다. 정렬 방향은 맞지만 전환 순간의 전체 스프라이트 팝이 자연스러운지는 실제 WASD로 통·상자·벽의 양쪽 모서리를 돌아보며 확인해야 한다.
- 네이티브 WASD에서 쥐가 물리적으로 멈춘 뒤에도 오브젝트 표면 안으로 파고들어 보이거나, 전환선에서 앞뒤가 반복 점멸하면 **수정 필요**로 재분류한다. 현재 정지 캡처와 MCP 수치만으로는 해당 현상이 확인되지 않았다.

## 사용자 확인 항목

1. 통의 좌우 모서리를 앞→옆→뒤, 뒤→옆→앞 순서로 각각 한 번 통과한다.
2. 상자와 벽도 같은 경로로 통과한다.
3. 물리적으로 멈춘 상태에서 쥐 몸통이 표면 위에 올라탄 것처럼 보이는지 확인한다.
4. 방향을 짧게 반전할 때 앞뒤 순서가 두 번 이상 점멸하는지 확인한다.

위 네 항목에 문제가 없으면 사용자 피드백 두 항목 모두 화면상 종결 가능하다.
