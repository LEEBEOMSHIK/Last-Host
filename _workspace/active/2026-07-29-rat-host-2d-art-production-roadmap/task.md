1. 아트 범위를 UI, 환경 타일, 소품, 쥐 캐릭터, 조명·효과, Unity 반입·QA로 분해한다.

4. ChatGPT 이미지 후보와 실제 게임 규격 재제작 경계를 명시한다.
5. 각 승인 게이트에서 사용자가 무엇을 확인·결정해야 하는지 정리한다.
6. 프로토타입 범위를 넘는 전체 게임 아트 제작은 별도 범위로 남긴다.
