# 실제 게임 에셋 1차 비주얼 품질 게이트

## 목적

승인된 고품질 환경·쥐·HUD 마스터의 묘사 밀도와 자연형 품질을 유지한 채
반복 타일, 투명 스프라이트, 투명 HUD 모듈로 재제작되었는지 판정한다.

해상도, PNG 디코딩, RGBA, 투명 모서리, 공통 캔버스, 피벗, 해시와 파일명은
필수 기술 조건일 수 있으나 시각 품질을 대신할 수 없다. 이 조건을 모두
통과해도 마스터보다 명백히 단순하거나 저밀도면 `REWORK`다.

## 판정 입력과 순서

1. 승인 품질 마스터를 원본 크기로 본다.
   - `environment-quality-master.png`
   - 최종 SHA `6BB8AC96832D74988093BABEB798E2F4ADE5C96D62E07DA625C49D24B7C6CCFC`의
     `rat-side-walk-quality-master.png`
   - `hud-quality-master.png`
2. `artifacts/source-masters/`를 원본 크기로 마스터와 직접 대조한다.
   소스 보드 단계에서 결함이 있으면 후처리로 해결될 것이라 가정하지 않고
   즉시 `SOURCE REWORK`로 보고한다.
3. `artifacts/game-assets/`를 투명 배경과 어두운/밝은 체크 배경에서 100%로
   본다.
4. `artifacts/previews/`에서 50%, 100%, 확대 프리뷰를 함께 보고 작은 실제
   크기 가독성과 확대 픽셀 군집을 모두 대조한다.
5. 환경·쥐·HUD는 독립 판정한다. 한 묶음의 우수함이 다른 묶음의 실패를
   상쇄하지 않는다.

## 판정 등급

- `PASS`: 자동 반려 없음 + 묶음별 필수 품질 기준 전부 충족.
- `REWORK`: 실제 에셋 분리·크로마·배치·페인트오버 단계의 수정이 필요한
  경우.
- `SOURCE REWORK`: source master 자체의 투시·형태·재질·분리 보드 결함으로
  실제 에셋 후처리만으로 품질을 보존할 수 없는 경우.
- 경계 판정은 통과시키지 않는다. 마스터와 비교해 품질 등급이 불확실하면
  `REWORK`다.

## 공통 자동 반려

다음 중 하나라도 있으면 관련 묶음은 점수와 무관하게 `REWORK` 또는
`SOURCE REWORK`다.

1. 승인 마스터보다 한눈에 저밀도·저명암·단순 도형으로 보인다.
2. 마스터를 작은 크기로 단순 축소해 흐린 가장자리, 깨진 픽셀 군집,
   비정수 샘플링 또는 사진 축소 질감이 남았다.
3. 크로마 색, 밝은 테두리 halo, 반투명 녹색·자홍 fringe, 검은/흰 박스,
   지워지지 않은 보드 배경이 실제 외곽에 남았다.
4. 반복·알파·셀 규격을 맞추기 위해 귀·코·꼬리·발·벽 모서리·베벨·
   하이라이트 같은 품질 핵심을 잘랐다.
5. 같은 세계의 환경·쥐·HUD 사이에 논리 픽셀 크기, 외곽선 두께, 광원
   방향 또는 재질 밀도가 명백히 다르다.
6. 단순 Pillow 도형, 균일 선분, 기본 그라디언트, 기계적 반복 무늬로
   재드로잉한 흔적이 보인다.
7. 문자, 로고, 워터마크, 프레임 번호, 생성 보드 구분선 또는 의도하지 않은
   물체가 실제 에셋에 섞였다.
8. 기술 검사 통과만을 근거로 마스터 대비 시각 품질 하락을 허용했다.

## 환경

### source master 게이트

- clean/worn 바닥, straight/corner 벽, center/edge 수로, 통·상자·배수구가
  서로 접촉하지 않는 분리 가능한 형태로 존재해야 한다.
- 모든 모듈이 동일한 아이소메트릭 축, 상면:측면 비율, 광원 방향과 픽셀
  밀도를 따라야 한다.
- 모듈 가장자리에 다른 물체 그림자·바닥 조각·배경 노이즈가 붙어 있으면
  분리 단계에서 재질을 훼손하므로 `SOURCE REWORK`다.
- 벽 corner는 두 straight 벽을 잇는 실제 내부 또는 외부 깊이를 가져야
  하고, 단순 복사·겹침이나 다른 높이로 보이면 실패다.
- 수로 edge에는 물과 석재 경계, 젖은 띠, 깊이 그림자가 함께 있어야 한다.
  단순 청록 띠만 있으면 실패다.

### game asset 필수 품질

| 항목 | 통과 기준 |
| --- | --- |
| 반복 | clean/worn 4×4 검사에서 외곽 이음선, 명암 단절, 줄눈 중복, 오염의 십자 무늬가 100%와 50% 모두에서 먼저 보이지 않는다. |
| 투시 | 128×64 바닥·수로 셀과 straight/corner 벽이 공통 2:1 후보 격자를 따르고, 조립 방에서 벽 높이·바닥 단차·수로 깊이가 흔들리지 않는다. |
| 재질 보존 | 석재 줄눈, 모서리 마모, 습윤 반사, 이끼·오염, 물결의 최소 4단계 명도와 군집이 마스터와 같은 등급으로 남는다. 단순 색상 블록으로 축소되지 않는다. |
| 변형 차이 | floor clean과 worn은 동일 셀 계열이면서 오염·균열·마모가 읽히게 다르고, 서로 다른 투시·팔레트의 별도 타일처럼 보이지 않는다. |
| 벽 | straight와 corner의 상면 폭, 벽돌 높이, 줄눈 주기, 명암 방향이 맞고 조립 경계에서 블록이 늘어나거나 꺾이지 않는다. |
| 수로 | center 반복에서 물결·하이라이트가 끊기지 않고 edge 조립에서 물–벽 경계, 젖은 석재와 깊이가 유지된다. |
| 소품 | 통·상자·배수구가 마스터의 나무·금속 재질과 입체감을 보존하고, 같은 투시·광원·픽셀 밀도를 따른다. 실루엣이 잘리거나 바닥에 녹지 않는다. |
| 방 프리뷰 | 중앙 이동 경로가 1초 안에 읽히고 소품·재질 디테일이 경로보다 먼저 튀지 않는다. 빈 단색 면이나 동일 패턴의 넓은 반복이 장면 품질을 낮추지 않는다. |

### 환경 자동 반려

- 4×4에서 단일 타일 윤곽이 격자처럼 즉시 보임
- 마스터의 재질을 잃고 큰 V·점·대각선 같은 기계적 무늬로 대체
- wall corner의 벽 높이·상면 폭·벽돌 투시 불일치
- 수면이 단색 또는 흐린 그라디언트이고 물결·젖은 경계·깊이 없음
- 통·상자·배수구가 정면/탑다운으로 보이거나 환경보다 다른 픽셀 배율

## 쥐

### source master 게이트

- neutral/contact/passing 3포즈가 서로 겹치지 않고 꼬리 끝·발가락·수염까지
  분리 가능해야 한다.
- 최종 승인 마스터와 같은 자연형 갈색 쥐여야 한다. 코끝–엉덩이, 몸통
  높이·복부 깊이·골반 체적, 얼굴·귀·꼬리 정체성이 자체 ±5% 범위다.
- source 단계에서 프레임별 배경색·그림자·외곽 대비가 달라 크로마 제거
  품질이 흔들릴 가능성이 보이면 `SOURCE REWORK`다.
- 추가 팔다리, 발 융합, 꼬리 단절, 다른 눈·귀 크기, 프레임별 광원 변화는
  후처리로 덮지 않고 source 결함으로 보고한다.

### game asset 필수 품질

| 항목 | 통과 기준 |
| --- | --- |
| 공통 캔버스 | 세 프레임이 256×192 동일 셀에 들어가며 귀·코·꼬리·발·수염이 잘리지 않는다. 빈 여백이 프레임마다 임의로 달라 보이지 않는다. |
| 동일 개체 | 코끝–엉덩이, 등 최고점, 몸통 높이·복부 깊이·골반 체적, 머리·귀·눈·코·꼬리 길이와 굵기가 원본 및 50%에서 약 ±5% 안으로 유지된다. |
| 접지선 | 발 최저점과 논리 접지선이 세 프레임에서 동일하며 몸통이 프레임 교체 때 떠오르거나 가라앉지 않는다. pivot은 이 시각 접지와 일치해야 한다. |
| 보행 | 공통 체형을 유지한 채 앞·뒤 다리 위상과 작은 어깨·골반 리듬으로 neutral/contact/passing이 구분된다. 몸통을 늘이거나 줄여 포즈 차이를 만들지 않는다. |
| 자연형 품질 | 등–목–머리 곡선, 좁아지는 주둥이, 골반 질량, 귀 안쪽, 눈 하이라이트, 코·수염·발가락·털 흐름과 가는 꼬리가 마스터 대비 명백히 단순해지지 않는다. |
| 알파 외곽 | 귀, 발가락, 수염, 꼬리의 가는 외곽에 크로마 halo·톱니형 덩어리·반투명 박스가 없다. 체크 배경의 밝고 어두운 양쪽에서 확인한다. |
| 50% 가독성 | nearest 50%에서 진행 방향, 귀·코·꼬리와 발의 리듬이 읽힌다. 눈·코가 뭉치거나 꼬리가 끊기지 않는다. |
| 시트 | 768×192 시트의 세 셀이 개별 PNG와 시각적으로 동일하며 경계 bleed, 1px 밀림, 잘못된 순서가 없다. |

### 쥐 자동 반려

- 프레임별 몸통 폭·높이·골반 체적이 ±5%를 넘거나 다른 개체로 보임
- 공통 접지선인데도 발이 떠 있거나 몸 중심이 팝함
- 수염·발가락·꼬리 끝을 알파 정리 과정에서 삭제·뭉개거나 크로마 halo 잔류
- 100%에서는 세부가 있으나 50%에서 햄스터형 원·사각 머리로 붕괴
- 스크립트 도형 재드로잉으로 마스터 털·해부·명암을 대체

## HUD

### source master 게이트

- 쥐 초상, 황동 초상 프레임, 공용 바 프레임, 붉은 채움, 청록 채움이
  독립 분리 가능한 영역이어야 한다.
- 초상은 쥐 게임 에셋과 같은 갈색 자연형 개체여야 하며 귀·눈·코가 다른
  종·나이처럼 보이면 `SOURCE REWORK`다.
- 황동 외곽과 내부 그림자, 게이지 유리·액체 하이라이트가 보드 배경과
  융합되어 있으면 소스 단계 실패다.

### game asset 필수 품질

| 항목 | 통과 기준 |
| --- | --- |
| 독립 모듈 | 초상, 프레임, 공용 바, red/teal 채움이 독립 RGBA로 조립되며 모듈 사이에 배경 조각·중복 테두리·틈이 없다. |
| edge 품질 | 황동 베벨, 모서리 마모, 안쪽 어두운 금속 외곽이 밝고 어두운 배경 모두에서 깨끗하고 1px halo·잘림이 없다. |
| 재질 보존 | 황동, 어두운 금속·석재, 붉은/청록 유리·액체의 군집과 하이라이트가 마스터 대비 단순 도형·기본 그라디언트로 축소되지 않는다. |
| 상태 조립 | empty/half/full에서 채움이 프레임 안에 정확히 마스킹되고 베벨·끝캡·분절을 침범하거나 틈을 만들지 않는다. |
| 상태 대비 | red/teal이 색뿐 아니라 명도·내부 발광·분절에서도 구분되며 50%에서도 읽힌다. empty 영역과 filled 영역도 즉시 구분된다. |
| 초상 | 쥐 얼굴의 귀·눈·코·수염이 프레임에 잘리지 않고 HUD 마스터 및 월드 쥐와 같은 개체 계열로 읽힌다. |
| 월드 조화 | 100%와 50% 모두에서 월드보다 선명하지만 지나치게 밝은 현대식 플랫 UI로 뜨지 않는다. |

### HUD 자동 반려

- 프레임 분해 과정에서 베벨·코너·마모가 잘려 단색 테두리가 됨
- red/teal 채움에 크로마 fringe, 배경 박스 또는 모듈 경계선 잔류
- empty/half/full 중 하나라도 채움이 프레임 밖으로 새거나 끝캡과 충돌
- 초상과 월드 쥐의 얼굴·귀·색이 다른 개체로 보임
- 50%에서 게이지 분절과 상태 대비가 합쳐져 읽히지 않음
