## 작업명

2단계 2D 백혈구 회피 미니게임과 성공·실패 인계

## 사용자 승인

- 승인일: 2026-07-28
- 사용자 요청: `2단계 2D 백혈구 회피 미니게임과 성공·실패 복귀 작업 진행해`
- 해석: 기존 단계적 2D 이관 브리프의 2단계 구현을 시작한다.
- 경계: 성공은 `MutationSelection` 인계 셸까지, 실패는 변이 보상 없이 `RatHost`로 복귀한다. 실제 변이 선택·효과와 성공 후 쥐 복귀는 3단계다.
- 예외: 1단계의 원본 Unity MCP Play·최신 QA 빌드는 외부 씬 변경 모달로 아직 차단되어 있다. 사용자의 이번 요청으로 2단계 구현은 시작하되, 1단계 검증 완료를 소급 주장하지 않는다.

## 목적

별도 `RatHost2DPrototype` 씬의 내부 전환 셸을 실제 2D 백혈구 회피 미니게임으로 교체한다. 바이러스를 이동해 변이 조각 3개를 수집하면 성공 모드로 인계하고, 백혈구 접촉으로 안정도가 0이 되면 실패 UI를 거쳐 보상 없이 쥐 모드로 복귀하게 한다.

## 루프 단계

1. 오염 노출로 면역 경계도 100%에 도달한다.
2. `WhiteBloodCellEvasion` 내부 모드에 진입한다.
3. 바이러스를 이동해 백혈구를 피하고 조각 3개를 수집한다.
4. 성공하면 `MutationSelection` 인계 셸을 표시한다.
5. 실패하면 `면역 반응 돌파 실패` UI를 표시하고 확인 입력 뒤 쥐 모드로 복귀한다.
6. 실패 복귀 면역 경계도는 `60%`, 새 변이는 `0`이며 다음 진입 상태는 초기화된다.

## 구현 수치

- 조각 목표: `3`
- 바이러스 시작 안정도: 기존 `PrototypeConfig.VirusStartingStability`
- 백혈구 1회 접촉 피해: 기존 `PrototypeConfig.VirusWhiteBloodCellDamage` (`34`)
- 백혈구 1회 접촉 포착 흔적: `면역 포착 +8`
- 실패 복귀 면역 경계도: `60%`
- 한 물리 접촉의 중복 피해 방지: 2D 접촉 쿨다운 또는 동등한 결정론적 게이트
- 성공·실패 동시 조건: 성공 우선

## 수용 기준

- Host 입력과 Virus 입력이 같은 프레임에 동시에 처리되지 않는다.
- 바이러스 root·Visual·카메라가 분리되거나 방향 반전 시 순간이동하지 않는다.
- 바이러스는 내부 아레나 벽을 통과하지 않는다.
- 백혈구 1종은 활성 내부 모드에서만 바이러스를 추적한다.
- 같은 물리 접촉에서 중복 피해·포착 흔적이 발생하지 않는다.
- 변이 조각은 각 1회만 집계되고 세 번째 조각에서 성공 전이가 정확히 한 번 발생한다.
- 같은 프레임에 세 번째 조각과 치명 접촉이 겹치면 성공을 우선한다.
- 성공 후 `MutationSelection` 인계 셸이 표시되고 Host·Virus 입력과 내부 충돌이 모두 정지한다.
- 실패 후 실패 UI가 표시되며 확인 전에는 쥐 입력이 활성화되지 않는다.
- 실패 확인 뒤 새 변이 없이 쥐 모드, 면역 경계도 `60%`로 복귀한다.
- 성공·실패·재진입을 반복해도 조각, 안정도, 백혈구 위치, 패널 상태가 남지 않는다.
- 기존 3D 씬, `RatHost2DTechnicalSample`, 입력 자산, Packages, ProjectSettings를 의도 없이 변경하지 않는다.

## 테스트 시나리오

1. 내부 진입 전 Host만 활성, 내부 진입 후 Virus만 활성인지 확인한다.
2. 바이러스 WASD 이동·방향 정합·아레나 충돌을 확인한다.
3. 백혈구 접촉 한 번이 안정도 `34` 감소와 포착 `+8` 한 번만 만드는지 확인한다.
4. 조각 1·2개에서는 진행, 3개째에 성공과 `MutationSelection` 단일 인계를 확인한다.
5. 안정도 0에서 실패 패널, 확인 전 입력 잠금, 확인 후 `RatHost`·경계도 `60%`·무보상을 확인한다.
6. 세 번째 조각과 치명 접촉을 같은 판정 프레임에 넣어 성공 우선을 확인한다.
7. 성공·실패 뒤 재진입해 모든 내부 런타임 상태 초기화를 확인한다.
8. 전체 EditMode, Unity MCP Play, Console Error/Warning, Windows 임시 빌드와 보호 diff를 확인한다.
