## S0 사용자 원증상·검증 charter

- 사용자 원문 또는 원증상: 혼합 먹이망·감염 경로를 사용하고, 각 동물의 생활권 맵을 연결하며, 다음 지역 진입 후에도 현재 숙주가 이용 가능한 경로로 이전 맵에 복귀할 수 있게 문서로 먼저 정리한다.
- 재현 씬·입력·좌표·상태: 해당 없음 — 문서 계약
- 원증상 증거: 대화 승인과 기존 `game-design-summary.md`·`main-scenario-outline.md`에는 숙주와 환경 후보만 있고 통합 맵 그래프가 없음
- 합성 oracle의 금지 결과: 단일 먹이사슬 강제, 새를 쥐 아래에 배치, 파지가 동물 세포를 직접 감염한다고 서술, 전체 캠페인 구현 승인으로 확대, 이전 지역 영구 폐기
- 합성 oracle의 허용 결과: 혼합 전이, 포식성 조류의 상위 배치, 거시 숙주/세균 숙주 구분, 조건부 이전 맵 복귀, 장기 제안과 프로토타입 승인 분리
- 완료 주장 한 문장: 한 문서에서 숙주 범위, 생활권 지역군, 전이 유형, 대표 분기, 조건부 회귀와 승인 경계를 확인할 수 있다.
