# 품질 우선 수직 샘플 비주얼 게이트

## 판정 목적

이번 작업은 기술 규격 시험이 아니라 `목표 목업의 시각 품질에 가까운 제작
마스터를 만들 수 있는가`를 먼저 증명하는 작업이다. 해상도, RGBA, 파일명,
피벗, 해시 재현성 같은 기술 검사는 필수 조건일 수 있으나 시각 품질을
대신하지 못한다. 기술 검사가 모두 통과해도 아래 시각 게이트 중 하나라도
실패하면 해당 묶음은 `REGENERATE`다.

## 공통 판정 방법

- 아래 4개 기준 이미지를 원본 크기로 직접 대조한다.
  - 목표 화면: `docs/design/visual/references/rat-host-2d-isometric-gameplay-mockup-v1.png`
  - 환경 기준: `environment-integrated-target.png`
  - 쥐 기준: `rat-integrated-target-v2.png`
  - HUD 기준: `hud-integrated-target.png`
- 후보도 원본 크기로 보고, 필요하면 100%와 200%에서 픽셀 군집을 함께 본다.
- `PASS`는 최종 게임 에셋 승인이 아니라 고품질 제작 마스터 후보로서 다음
  재제작 단계에 넘길 수 있다는 뜻이다.
- 세 묶음은 독립 판정한다. 하나의 우수한 묶음이 다른 묶음의 실패를 상쇄하지
  않는다.
- 총점보다 자동 반려 조건이 우선한다. 자동 반려가 없을 때만 항목별 게이트를
  적용한다.

## 공통 자동 반려 조건

다음 중 하나라도 보이면 점수와 무관하게 `REGENERATE`다.

1. 단순 타원·사각형·선분을 겹친 Pillow 플레이스홀더처럼 읽힌다.
2. 목표 목업보다 묘사 밀도와 명암 단계가 명백히 낮아 첫눈에 다른 등급의
   그래픽처럼 보인다.
3. 픽셀 군집이 기계적으로 동일 반복되거나, 픽셀 아트가 아니라 저해상도
   사진 축소·과도한 디더링·흐린 리샘플처럼 보인다.
4. 문자, 로고, 워터마크, 격자, 프레임 번호 또는 의도하지 않은 물체가 있다.
5. 제3자 게임이나 작가의 고유 캐릭터·UI를 식별 가능하게 복제했다.
6. 생성 잘림, 여분 팔다리, 비정상 해부, 뒤틀린 투시, 물체 융합 등 생성
   결함이 플레이 크기에서 보인다.
7. 밝기와 디테일이 전 화면에 균등해 플레이어·경로·상태 정보의 시선
   우선순위가 없다.

## 환경 품질 마스터

### 필수 통과 기준

| 항목 | 통과 기준 |
| --- | --- |
| 아이소메트릭 공간 | 바닥·벽·수로·대표 소품의 평행축과 깊이 단계가 한 장면 안에서 일관되고, 걷기 가능한 경로가 1초 안에 구분된다. |
| 재질 구분 | 석재 바닥, 벽돌 벽, 물, 이끼·오염, 젖은 면, 나무·금속 소품 중 최소 6종이 색만이 아니라 픽셀 군집·경면·모서리 마모 방식으로 구분된다. |
| 명암 깊이 | 장면에 최소 4개의 읽히는 명도 역할(최심부, 구조 그림자, 기본 재질, 하이라이트)이 있고, 따뜻한 광원과 차가운 수로의 대비가 목표 목업 수준으로 분명하다. |
| 환경 밀도 | 화면의 주요 바닥·벽 영역 대부분에 줄눈, 마모, 습윤, 이끼, 반사 중 하나 이상의 의도적 정보가 있으면서, 이동 경로 중앙은 주변보다 한 단계 단순하다. 빈 평면이나 동일 무늬의 넓은 반복이 시각 면적의 약 20%를 넘지 않는다. |
| 구조 가독성 | 최소 3개의 깊이 층(전경 가장자리/이동 바닥/후면 벽 또는 수로)이 즉시 읽히며 벽 높이, 수로 경계, 낙하 가장자리가 섞이지 않는다. |
| 소품 품질 | 통·상자·배수구가 각각 재질과 입체감을 가지며, 바닥에 붙거나 녹아 보이지 않고 동일 투시와 광원을 따른다. |
| 목업 정합 | 목표 목업 및 환경 통합 기준과 나란히 봤을 때 `고밀도 어두운 하수도 도트 아트`라는 동일한 제품군으로 읽힌다. 구성은 달라도 품질 등급은 명백히 낮지 않아야 한다. |

### 환경 전용 자동 반려

- 큰 단색 면, 규칙적인 V자·점무늬, 동일 블록 복제처럼 보이는 자동 생성 흔적
- 벽돌 줄눈·수면 물결·바닥 투시가 서로 다른 소실 방향을 따름
- 물이 단순한 청록 단색 띠이고 젖은 경계·반사·깊이 차가 없음
- 조밀함을 무작위 노이즈로 대신해 경로와 소품 실루엣이 묻힘

## 쥐 품질 마스터

### 필수 통과 기준

| 항목 | 통과 기준 |
| --- | --- |
| 자연형 실루엣 | 세 프레임 모두 낮고 긴 몸, 등–어깨–목–머리의 연속 곡선, 좁아지는 주둥이, 골반 질량과 가는 꼬리가 읽힌다. 원형 몸통+사각 머리, 햄스터형 구체, 검은 초승달 음영으로 보이지 않는다. |
| 해부·접지 | 앞·뒤 다리의 관절 방향과 발 위치가 보행 포즈에 맞고, 최소 두 발의 접지 또는 명확한 체중 지지가 읽힌다. 몸이 떠 있거나 발이 몸통에 무작위로 붙지 않는다. |
| 개체 동일성 | 정지·접촉·통과 3프레임의 몸통 길이와 높이, 머리 크기, 귀 크기·간격, 눈·코 위치, 꼬리 굵기·길이가 육안 기준 약 ±5% 안에서 유지된다. 자세 변화 외에 종·나이·체중이 바뀐 것처럼 보이면 실패다. |
| 프레임 안정성 | 공통 지면선을 기준으로 발과 몸 중심의 수직 변화가 자연스러운 보행 범위에 머문다. 몸 전체가 임의 확대·축소되거나 좌우로 순간 이동하는 인상이 없어야 한다. |
| 포즈 차이 | 접촉과 통과 자세에서 앞·뒤 발의 위상, 어깨·골반 높이, 꼬리 기저부가 실제 보행으로 구분된다. 정지 프레임을 부분 변형한 3개 복제처럼 보이지 않는다. |
| 자연형 세부 | 귀의 얇은 안쪽, 눈 하이라이트, 코, 수염, 발가락, 털 흐름이 목표 쥐 기준과 비슷한 정교함으로 표현되며 세부가 실루엣을 깨뜨리는 노이즈가 아니다. |
| 광원·팔레트 | 세 프레임의 주광 방향, 몸통 중간색·그림자·하이라이트와 분홍 귀·발·꼬리 팔레트가 동일하다. |
| 실제 플레이 가독성 | 원본 후보를 축소해 예상 플레이 점유율로 봐도 귀·코·꼬리 방향과 진행 방향이 즉시 읽힌다. 확대에서만 형태가 성립하면 실패다. |

### 쥐 전용 자동 반려

- 프레임별 머리·몸·귀·꼬리 비율이 달라 서로 다른 개체로 보임
- 발 수 오류, 팔다리 융합, 꼬리 단절·중복, 얼굴 왜곡
- 털을 일정한 대각선 줄이나 필터 질감으로만 표현
- 배경, 문자, 셀 테두리 때문에 실제 스프라이트 외곽 검토가 불가능
- 목표 V2의 자연형 쥐보다 뚜렷하게 만화형·블록형·저밀도임

## HUD 품질 마스터

### 필수 통과 기준

| 항목 | 통과 기준 |
| --- | --- |
| 재질 | 낡은 황동 외곽, 어두운 금속·석재 안쪽, 유리 또는 액체형 게이지가 색·모서리 마모·반사 방식으로 구분된다. |
| 프레임 정교함 | 얇은 외곽을 유지하면서 코너, 접합, 안쪽 베벨이 읽힌다. 두꺼운 단색 테두리나 단순 둥근 사각형으로 보이지 않는다. |
| 상태 대비 | 붉은 생명력과 청록 면역 게이지가 색각에만 의존하지 않고 명도·발광·내부 분절에서도 구분된다. 어두운 월드 위에서 즉시 읽힌다. |
| 초상 일치 | 초상 속 쥐가 쥐 품질 마스터와 같은 갈색 자연형 개체로 읽히며, 원형 프레임 안에서 귀·눈·코 실루엣이 잘리지 않는다. |
| 월드 조화 | 목표 HUD처럼 월드보다 선명하지만 과도하게 밝거나 현대적 플랫 UI처럼 뜨지 않는다. 황동 톤과 어두운 내부가 하수도 팔레트에 속한다. |
| 구현 분해 가능성 | 초상 프레임, 공용 바 프레임, 붉은 채움, 청록 채움의 경계가 시각적으로 명확해 후속 투명 모듈 재제작 기준으로 사용할 수 있다. |

### HUD 전용 자동 반려

- 단색 테두리, 기본 그라디언트, 단순 분할 막대로만 구성된 플레이스홀더
- 초상과 월드 쥐가 다른 종·색·나이처럼 보임
- 붉은/청록 상태가 어두운 화면에서 프레임과 합쳐져 읽히지 않음
- 글자·수치·로고·워터마크 포함

## 최종 판정

- `PASS`: 자동 반려 없음 + 해당 묶음의 필수 기준 전부 충족. 후속 게임
  규격 재제작의 품질 마스터 후보로만 승인.
- `REGENERATE`: 자동 반려 1개 이상 또는 필수 기준 1개 이상 실패.
- 경계 판정은 통과시키지 않는다. 목표 목업과 품질 차이가 육안으로 크게
  느껴지면 `REGENERATE`로 판정하고, 다음 생성에서 바꿀 한 가지 핵심
  지시를 우선 제시한다.
