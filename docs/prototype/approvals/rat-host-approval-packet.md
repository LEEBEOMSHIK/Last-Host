## 현재 확정된 방향

- 게임은 Unity 프로젝트로 진행한다.
- 첫 검증 목표는 `쥐 숙주 프로토타입`이다.
- 현재 비주얼·공간 표현은 2D 아이소메트릭/쿼터뷰 도트 타일과 방향별 캐릭터 스프라이트를 기준으로 한다.
- 2026-07-16의 3D 환경·저폴리 3D 원본 기반 하이브리드 2.5D 방향은 2026-07-27 사용자 승인으로 대체되었다. 기존 산출물은 레거시 기록으로 보존한다.
- 프로토타입은 숙주 조종, 면역 경계도, 내부 바이러스 미니게임, 변이 선택 후 복귀의 최소 루프를 검증한다.
- 쥐는 벌레보다 상위 숙주지만, 첫 프로토타입에서는 정식 진행 순서가 아니라 핵심 루프 검증용 수직 슬라이스로 사용한다.
- 1차 프로토타입에는 벌레 튜토리얼을 포함하지 않는다.
- Unity 프로젝트 루트는 `UnityProject/`다.
- Unity 프로젝트 표시 이름은 현재 `My project`를 유지한다.
- Unity MCP는 읽기 호출이 가능한 상태이며, MCP를 통한 변경 작업은 별도 승인 대상이다.

## 승인 완료 항목

### 1. Unity 버전

- 현재 상태: `6000.4.6f1`
- 추천 결정: 1차 프로토타입은 현재 버전으로 고정한다.
- 이유: 이미 프로젝트가 해당 버전으로 생성되어 있고, 버전 변경은 ProjectSettings와 패키지 재검증 비용을 만든다.

### 2. URP 사용

- 현재 상태: URP 패키지와 렌더 파이프라인 설정 에셋이 포함되어 있다.
- 추천 결정: 1차 프로토타입은 URP를 사용한다.
- 이유: 기존 프로젝트 설정을 불필요하게 교체하지 않고, 2D Renderer·2D 조명·Pixel Perfect Camera 적용 여부를 기술 샘플에서 검증할 수 있다.

### 3. 플랫폼

- 현재 방향: PC 우선
- 추천 결정: 1차 프로토타입은 PC 키보드 조작만 검증한다.
- 이유: 모바일 입력과 화면 배치는 핵심 루프 검증 이후로 미뤄도 된다.

### 4. 시작 범위

- 확정 결정: 쥐 숙주부터 바로 시작한다.
- 해석: 쥐는 벌레보다 상위 숙주지만, 첫 프로토타입은 정식 진행 순서가 아니라 하수도 쥐 구간만 잘라 핵심 루프를 보는 수직 슬라이스다.
- 제외: 벌레 튜토리얼은 1차 프로토타입에 넣지 않는다.
- 이유: 현재 프로토타입 목표는 숙주 조종, 면역 전환, 변이 복귀 루프 검증이며, 벌레 튜토리얼은 범위를 늘린다.

### 5. 초기 조작 방식

- 추천 결정:
  - 이동: `WASD`
  - 상호작용: `Space`
  - 카메라: 고정 2D 아이소메트릭/쿼터뷰
  - 마우스 조작: 1차 프로토타입에서는 제외
- 이유: 숙주 모드와 바이러스 모드의 조작을 단순하게 맞춰 루프 이해를 우선한다.

### 6. 성공과 실패 조건

- 추천 성공 조건:
  - 쥐 모드에서 면역 경계도 100%에 도달하면 내부 바이러스 미니게임으로 전환한다.
  - 바이러스 미니게임에서 바이러스 안정도가 0이 되기 전에 변이 조각 3개를 수집하면 성공한다.
  - 성공 시 변이 1개를 선택하고 쥐 모드로 복귀한다.
- 추천 실패 조건:
  - 바이러스 안정도가 0이 되면 미니게임 실패로 처리한다.
  - 1차 프로토타입에서는 실패 화면을 보여준 뒤 보상 없이 쥐 모드로 복귀하며, 영구 사망이나 런 종료는 구현하지 않는다.
- 이유: 실패가 전체 루프 검증을 막지 않게 하면서도 내부 미니게임의 압박은 확인할 수 있다.

### 7. 초기 UI 게이지

- 추천 포함:
  - 숙주 생명력
  - 면역 경계도
  - 현재 모드
  - 바이러스 안정도
  - 변이 조각 수
- 추천 제외:
  - 침식도
  - 공존도
  - 인간 위험도
  - 백신 개발도
- 이유: 첫 빌드에서는 루프 이해에 직접 필요한 정보만 보여준다.

### 8. 프로토타입 변이 효과

| 변이 | 1차 프로토타입 임시 효과 |
| --- | --- |
| 잠복 강화 | 쥐 모드 면역 경계도 상승 속도 감소 |
| 신경 조종 | 쥐 조종력을 높여 자유 조작에 가까워지고 이동 속도도 증가 |
| 포유류 적응 | 하수도 맵의 특정 통로 접근 허용 |

여기서 `1차 프로토타입 임시 효과`는 정식 다중 숙주 전이 효과가 아니다. 1차 빌드에 두 번째 숙주가 없기 때문에, `포유류 적응`을 골랐을 때 플레이어가 변화를 느낄 수 있도록 하수도 맵 안에서만 임시로 적용할 효과를 뜻한다.

`보상 지점 접근`은 후속 조정 대안으로만 남긴다. 1차 구현 기본값은 `특정 통로 접근`이다.

### 9. 플레이스홀더 에셋

- 추천 결정: 1차 프로토타입은 기본 도형과 단순 2D 도트 타일·스프라이트 플레이스홀더를 사용할 수 있다. 기존 3D 플레이스홀더는 2D 전환 검증이 끝날 때까지 레거시 비교용으로 보존할 수 있다.
- 제외: 완성형 애니메이션과 승인·규격화·QA를 거치지 않은 AI 생성 이미지
- 이유: 핵심 루프 검증 전에는 최종 아트 제작 비용을 쓰지 않는다.

### 10. 저장소와 Unity 메타 파일

- 현재 상태: Unity 프로젝트용 `.gitignore`가 있고, `.meta` 파일은 추적 대상이다.
- 추천 결정: 현재 정책을 유지한다.
- 이유: Unity 에셋 참조 안정성을 위해 `.meta` 파일은 저장소에 남겨야 한다.

### 11. 과거 캐릭터 비주얼 표시 방식

- 상태: 2026-07-16 승인, 2026-07-27 사용자 2D 전환 승인으로 대체
- 과거 승인 결정:
  - 환경·이동 공간·충돌·카메라는 Unity 3D로 유지한다.
  - 쥐·바이러스·백혈구는 저폴리 3D 원본을 방향·애니메이션 일관성의 제작 기준으로 둔다.
  - 게임 런타임에서는 3D 원본을 렌더한 8방향 스프라이트로 캐릭터를 표시한다.
- 보존 이유: 해당 결정으로 제작된 구현과 Blender 산출물의 승인·비교 이력을 추적하기 위해 삭제하지 않는다.

### 12. 현재 2D 아이소메트릭 비주얼·공간 표현

- 승인 결정:
  - 환경·이동 공간은 2D 아이소메트릭 도트 타일맵으로 전환한다.
  - 쥐·바이러스·백혈구와 효과는 방향별 2D 도트 스프라이트로 제작한다.
  - 카메라는 고정 아이소메트릭/쿼터뷰로 두고, 충돌·가림·앞뒤 관계는 2D 충돌 영역과 Y축 깊이 정렬을 기준으로 한다.
  - 기존 3D 환경·저폴리 원본·Blender 프리렌더 파이프라인은 신규 제작 기본 경로에서 제외하고 레거시로 보존한다.
  - `docs/design/visual/references/rat-host-2d-isometric-gameplay-mockup-v1.png`를 목표 분위기·구도 reference로 사용한다.
  - ChatGPT 내장 이미지 생성은 목업·콘셉트·스프라이트 초안 제작에 연계할 수 있다. 생성 결과는 작업 패킷에 기록하고 사람의 선별, 게임 규격 재제작, QA를 거친다.
- 승인에 포함하지 않는 항목:
  - 최종 타일 크기, 프레임 해상도와 PPU
  - 동작별 프레임 수와 재생 속도
  - 최종 타일셋·스프라이트·애니메이션 제작
  - Tilemap, 2D 물리, SpriteRenderer, Animator, 그림자, 깊이 정렬의 실제 Unity 구현
  - 목업 이미지를 실제 타일셋이나 최종 에셋으로 직접 사용하는 결정
- 이유: 목업에서 확인한 자연스러운 캐릭터와 통일된 도트 환경을 프로젝트 전체의 실제 플레이 화면 방향으로 삼기 위함이다.

### 13. 단계적 2D 핵심 루프 이관과 1단계 구현

- 승인 결정:
  - 핵심 루프를 `숙주·면역·전환 → 백혈구 회피 성공/실패 → 변이·복귀` 세 단계로 이관한다.
  - 첫 구현은 `2D 쥐 숙주 탐험 + 숙주 본능/WASD 인계 + 면역 경계도 + 자연 100% + 내부 모드 전환 셸`까지만 진행한다.
  - `RatHost2DTechnicalSample.unity`는 기술 회귀 기준으로 보존하고 별도 `RatHost2DPrototype.unity`를 만든다.
  - 기존 `PrototypeSessionState`와 차원 독립 상태·테스트를 재사용하고 3D 물리·카메라·표현·씬 연결부만 2D로 교체한다.
  - 시간 경과 기본 면역 상승은 `0`을 유지하고 `ContaminationExposure` 오염 구역을 통해 자연 100%에 도달한다.
  - 2단계는 백혈구 회피형을 우선하며, 소음·강제 조종 면역 트리거와 면역 신호 억제형은 별도 이관 전까지 2D 최소 경로에 노출하지 않는다.
  - 3단계에서 잠복 강화가 위험 행동 경계도 상승량에도 `0.55` 배율을 적용하도록 보완한다.
  - 기존 3D 씬과 2D 기술 샘플은 전체 루프 수용 후에도 별도 정리 승인 전까지 보존한다.
- 1단계에 포함하지 않는 항목:
  - 실제 바이러스 이동·백혈구·변이 조각
  - 성공·실패 결과와 쥐 모드 복귀
  - 변이 선택·효과
  - 시간 자동 상승 재활성화
  - 최종 아트·PPU·타일·화면 규격
  - 기존 3D/2.5D/Blender 산출물 삭제
- 근거 문서: `approvals/rat-host-2d-core-loop-migration-brief.md`

## 승인 이력

- 2026-06-30: 사용자가 프로토타입이므로 전체 승인한다고 응답했다.
- 전체 추천안 승인으로 처리했다.
- 선택지가 남아 있던 `포유류 적응` 임시 효과는 기존 추천안의 첫 후보인 `특정 통로 접근`으로 확정했다.
- 2026-07-16: 사용자가 `쥐 프로토타입부터 캐릭터는 3D 원본 기반 8방향 스프라이트로 전환하고, 환경은 3D로 유지`하는 방향을 승인하고 관련 프로젝트 문서 갱신을 요청했다.
- 2026-07-27: 사용자가 목업 기반 `2D 아이소메트릭/쿼터뷰 도트 게임`으로 프로젝트 전체 비주얼·공간 표현을 전환하도록 승인했다. 이 결정은 2026-07-16의 하이브리드 2.5D 방향을 대체하며, 기존 이력과 산출물은 레거시로 보존한다.
- 2026-07-28: 사용자가 단계적 2D 이관 브리프 설명 후 `좋아. 계속 진행해`라고 응답했다. 전체 추천안 승인과 1단계 실제 Unity 구현 착수 승인으로 기록했다.
