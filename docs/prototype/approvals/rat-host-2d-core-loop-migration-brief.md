# 쥐 숙주 핵심 루프 단계적 2D 이관 승인 브리프

작성일: 2026-07-27
승인일: 2026-07-28
문서 상태: 전체 추천안 승인 완료 — 2단계 구현 후보·자동 기술 게이트 통과, 원본 적용·MCP 검증 사용자 결정 대기
대상: 쥐 숙주 1차 프로토타입의 기존 핵심 루프를 승인된 2D 아이소메트릭 구조로 이관하는 작업

## 한눈에 보는 추천안

다음 구조로 세 단계에 나눠 이관한다.

1. `2D 쥐 숙주 탐험 + 숙주 본능/WASD 인계 + 면역 경계도 + 100% 모드 전환`
2. `2D 백혈구 회피 미니게임 + 성공·실패 복귀`
3. `변이 선택 + 효과 적용 + 2D 쥐 숙주 복귀`

초기 착수 권고는 **1단계만** 진행하는 것이었고, 이후 사용자가 2단계 구현을 추가 승인했다.

- `RatHost2DTechnicalSample.unity`는 이동·충돌·카메라·Y 정렬 회귀 기준으로 보존한다.
- 실제 핵심 루프는 별도 `RatHost2DPrototype.unity`에서 구성한다.
- `PrototypeSessionState`를 비롯한 차원 독립 상태·규칙은 재사용한다.
- 3D 물리·카메라·표시·씬 연결부만 2D 컴포넌트로 교체한다.
- 기존 `RatHostPrototype.unity`는 전체 2D 루프 수용 뒤에도 자동 삭제하지 않고 레거시로 보존한다.

이 승인은 최종 타일·PPU·해상도·스프라이트·HUD 아트를 확정하는 승인이 아니다.

## 이 문서가 필요한 이유

사용자 수용을 받은 2D 기술 샘플은 다음 기술을 검증했다.

- 화면 기준 WASD와 8방향 표시
- 방향 반전·무입력 정지 시 순간이동과 위치 이탈 없음
- 벽·수로·Pipe·Barrel의 2D 충돌
- 쥐와 같은 논리 위치를 따르는 픽셀 카메라
- 발 접지점 기준 Y 정렬
- 최소 HUD와 Windows 임시 빌드 생성

아직 이관하지 않은 범위는 다음과 같다.

- 숙주 본능 이동과 실제 WASD 인계
- 면역 경계도와 위험 행동
- 100% 모드 전환
- 내부 바이러스 미니게임
- 성공·실패 복귀
- 변이 선택과 효과

기술 샘플을 바로 전체 게임 씬으로 계속 확장하면 이미 검증한 이동 기반과 새 상태 통합 문제가 섞인다. 따라서 기술 샘플을 고정 회귀 기준으로 남기고 별도 프로토타입 씬에서 핵심 루프를 단계적으로 조립한다.

## 현재 규칙과 이관 원칙

### 유지할 게임 규칙

- 무위험 대기와 일반 이동만으로 면역 경계도가 오르지 않는다.
- 현재 `PrototypeConfig.BaseAlertPerSecond` 기본값은 `0`이다.
- 오염 노출처럼 원인이 보이는 위험 행동으로 경계도가 오른다.
- 1단계 기본 위험은 `ContaminationExposure`로 라우팅되는 2D 오염 구역 1종이다.
- 현재 시험값은 오염 구역 체류 시 경계도 `+12/초`, 숙주 생명력 `-4/초`다.
- 면역 경계도 100% 도달 이벤트는 한 번만 발생한다.
- 내부 미니게임은 우선 백혈구 회피·변이 조각 3개 수집형 1종을 사용한다.
- 성공과 실패가 같은 판정 프레임에 발생하면 성공을 우선한다.
- 실패 시 새 변이 없이, 성공 복귀보다 높은 면역 경계도를 남기고 쥐 모드로 복귀한다.
- 성공 시 세 가지 변이 중 하나만 선택해 적용한다.

`자연 경계도 100%`는 디버그 강제 전환이 아니라, 플레이어가 실제 쥐 모드에서 위험 행동을 반복해 원인 피드백과 함께 100%에 도달하는 흐름을 뜻한다.

현재 `NoiseOrTissueIrritation`과 `ForcedHostControl` 원인은 `ImmuneSignalSuppression`으로 라우팅된다. 2단계 추천안이 백혈구 회피형만 이관하므로, 소음 배관과 강제 조종 면역 트리거는 2D 최소 이관에서 잠시 노출하지 않는다. 숙주 본능 이동과 WASD 인계 자체는 1단계에 포함한다.

### 재사용할 상태·규칙

| 영역 | 재사용 대상 | 원칙 |
| --- | --- | --- |
| 공용 상태 | `PrototypeSessionState`, `PrototypeConfig`, `PrototypeGameMode` | 상태 인스턴스는 런타임에 하나만 둔다. |
| 면역 | `ImmuneAlertModel`, `ImmuneAlertEvent`, 원인 타입 | 수치·임계치·원인 피드백 규칙을 유지한다. |
| 내부 판정 | `VirusMinigameModel`, `VirusMinigameOutcome` | 조각 3개, 안정도, 성공 우선 규칙을 유지한다. |
| 변이 | `MutationLoadout`, `MutationType`, `MutationDefinition` | 세 변이와 승인된 임시 효과를 유지한다. |
| 기존 테스트 | 핵심 상태 EditMode 테스트 | 2D 이관 중에도 누적 회귀 기준으로 실행한다. |

### 2D로 교체할 부분

| 영역 | 기존 3D 결합 | 2D 이관 방향 |
| --- | --- | --- |
| 쥐 이동 | `CharacterController`, XZ 이동 | `Rigidbody2D`, `Collider2D`, 화면 기준 XY 이동 |
| 숙주 본능 | XZ `RatHostControlModel` | XY↔XZ 어댑터를 두고 기존 인계 규칙 재사용 |
| 위험·상호작용 | 3D Trigger/Collider | `Collider2D`와 2D 상호작용 범위 |
| 카메라 | 3D 모드별 카메라 | 검증된 `PixelFollowCamera2D` 계약 |
| 표시·깊이 | 3D/2.5D 표시와 Z 깊이 | 방향별 SpriteRenderer와 발 기준 Y 정렬 |
| 바이러스·백혈구 | XZ 이동과 3D 충돌 | 2D 아레나, Rigidbody2D/Collider2D |
| UI 연결 | 기존 3D 세션 컨트롤러 직접 참조 | 2D 세션 컨트롤러를 통한 상태 읽기·명령 |

## 추천 Unity 구조

### 씬

첫 전체 루프 수용까지는 additive 다중 씬이나 Bootstrap을 추가하지 않고, 별도 단일 씬의 모드 root를 전환한다.

```text
RatHost2DPrototype
  Core2D
    RatHost2DSessionController
  RatHostMode2D
    World2D
    RatHost2D
    HostCamera2D
  VirusMode2D
    VirusArena2D
    VirusPlayer2D
    WhiteBloodCells2D
    Fragments2D
    VirusCamera2D
  UI2D
    HostHud2D
    VirusHud2D
    MutationSelection2D
    FailurePanel2D
  EventSystem
```

한 프레임에 한 모드의 입력·충돌·UI만 활성화한다. UI는 상태를 직접 바꾸지 않고 2D 세션 컨트롤러에 명령만 전달한다.

### 어셈블리

1차 이관에서는 새 `LastHost.Prototype.RatHost2D` 어셈블리가 다음 두 어셈블리를 참조하는 방식을 추천한다.

```text
LastHost.Prototype.RatHost2D
  ├─ LastHost.Prototype
  └─ LastHost.Prototype.TechnicalSample2D
```

- 기존 어셈블리와 기술 샘플 코드는 1차 단계에서 이동·개명하지 않는다.
- 기술 샘플의 이동·카메라·정렬 기반만 조합하고 시험 HUD·Telemetry에는 제품 상태를 의존시키지 않는다.
- 공용 `Domain` 어셈블리 추출은 파일 이동과 기존 3D 회귀 위험이 있으므로 전체 2D 루프 수용 후 별도 작업으로 미룬다.

## 단계 1 — 2D 숙주·면역·100% 전환

### 포함

- 별도 `RatHost2DPrototype.unity`
- 수용된 2D 이동·충돌·카메라·Y 정렬
- 기존 숙주 본능 이동과 실제 WASD 인계
- 쥐 숙주 생명력, 면역 경계도, 현재 모드 HUD
- 2D 오염 구역 1종과 `오염 노출` 피드백
- 위험 행동을 통한 자연 경계도 100%
- `RatHost → InternalVirus` 단일 전환
- 전환 후 쥐 입력·위험 판정·숙주 HUD 비활성
- 플레이 미완성 내부 모드임을 명시하는 전환 검증 셸

### 제외

- 시간 경과 기본 면역 상승 재활성화
- 소음 배관·강제 조종 면역 트리거와 `ImmuneSignalSuppression` 진입
- 실제 바이러스 이동·백혈구·변이 조각
- 성공·실패 판정과 복귀
- 변이 선택과 효과 적용
- 면역 신호 억제 미니게임
- 최종 아트와 최종 PPU·타일·화면 규격

### 수용 기준

- 무위험 대기와 일반 이동 중 면역 경계도 증가가 `0`이다.
- 무입력 숙주 본능 이동과 WASD 인계 중 쥐 물리 root·Visual·카메라가 분리되지 않는다.
- WASD 활성 입력은 기존 숙주 본능 모델을 거친 뒤에도 실제 입력 방향과 일치한다.
- 방향 반전, 충돌, 본능 이동 중 순간이동·누적 오프셋·소품 관통이 없다.
- 오염 구역 바깥에서는 경계도·숙주 생명력 변화가 없고, 구역 안에서는 현재 시험값 `+12/초`, `-4/초`를 적용한다.
- 오염 노출 원인은 기본 백혈구 회피형으로 라우팅되고, 미구현 신호 억제 셸로 진입하지 않는다.
- 위험 행동으로 `99.x → 100`에 도달할 때 전환이 정확히 한 번 발생한다.
- 전환 프레임 이후 Host 입력·Trigger·상호작용이 상태를 추가 변경하지 않는다.
- 기존 핵심 상태 테스트, 3D 회귀 테스트, 2D 기술 샘플 테스트에 신규 실패가 없다.

### 1단계 완료 경계

1단계는 내부 미니게임이 완성되지 않은 **기술 통합 단계**다. 일반 플레이어용 완성 빌드로 선언하지 않는다. 자동 테스트, Unity MCP Play, 단계 전용 Windows 빌드로 전환 경계까지만 검증하고 2단계 전에는 전체 루프 완료를 주장하지 않는다.

## 단계 2 — 2D 내부 바이러스 미니게임·성공/실패

### 포함

- 2D 바이러스 이동과 아레나 충돌
- 백혈구 1종의 추적·접촉
- 바이러스 안정도와 변이 조각 3개
- 접촉 시 `면역 포착 +8`
- 성공 시 `MutationSelection` 인계
- 실패 UI와 보상 없는 쥐 모드 복귀
- 성공·실패 동시 판정 시 성공 우선
- 재진입 시 조각·안정도·백혈구·패널 초기화

### 제외

- 면역 신호 억제 미니게임의 2D 이관
- 소음·강제 조종 원인에서 신호 억제형으로 진입하는 2D 경로
- 복수 백혈구·항체·보스·절차 생성
- 변이 선택 효과 적용
- 최종 바이러스·백혈구 아트

### 수용 기준

- Host와 Virus 입력이 동시에 처리되는 프레임이 없다.
- 조각은 각각 한 번만 집계되고 세 번째 조각에서 성공이 한 번 발생한다.
- 백혈구 접촉이 한 물리 접촉에서 중복 피해를 내지 않는다.
- 실패 시 변이가 지급되지 않고 성공 복귀보다 높은 면역값으로 돌아간다.
- 성공·실패·재진입을 반복해도 이전 내부 상태가 남지 않는다.

## 단계 3 — 변이 선택·효과·2D 쥐 복귀

### 포함

- `잠복 강화`, `신경 조종`, `포유류 적응` 세 선택지
- 한 번의 보상에서 한 변이만 적용
- 성공 복귀 면역값과 내부 포착값 반영
- 잠복 강화의 면역 상승 억제
- 신경 조종의 조종력·이동 속도 향상
- 포유류 적응의 하수도 특정 통로 접근
- 성공·실패 전체 루프 Windows 실행본 검증

### 수용 기준

- 성공한 경우에만 변이 선택 화면이 나온다.
- 중복 입력에도 한 변이만 적용된다.
- 복귀 후 이전 모드 입력·충돌·UI가 비활성이다.
- 각 변이 효과를 쥐 모드에서 설명 없이 구분할 수 있다.
- 포유류 적응은 지정 통로만 열고 다른 충돌을 무효화하지 않는다.
- 성공과 실패 루프를 Windows 실행본에서 각각 완료할 수 있다.

### 잠복 강화 정합 문제

현재 잠복 강화는 `ImmuneAlertRateMultiplier = 0.55`지만 시간 경과 기본 상승이 `0`이므로, 기존 코드 그대로면 플레이어가 효과를 체감하기 어렵다.

추천은 **시간 자동 상승을 다시 켜지 않고, 잠복 강화가 위험 행동의 면역 상승량에도 `0.55` 배율을 적용하도록 3단계에서 규칙과 테스트를 보완하는 것**이다. 이는 승인된 “면역 경계도 상승 억제” 의도와 맞지만 현재 동작 변경이므로 사용자 승인을 받는다.

## 단계별 공통 검증 게이트

각 단계마다 다음을 누적 실행한다.

1. 기존 `RatHostPrototypeCoreTests`
2. 기존 `TechnicalSample2D` 전체 EditMode 테스트
3. 신규 상태 전이·2D 씬 계약·중복 명령·초기화 테스트
4. 기존 3D 씬과 기술 샘플 보호 경로 Git diff·해시 대조
5. Unity MCP Play에서 실제 Input Action, 모드 root, HUD, Collider2D, Console 확인
6. 단계별 Windows 임시 빌드 성공
7. 3단계에서 Windows 실행본 성공·실패 전체 루프 플레이와 사용자 수용

Windows 빌드 생성 성공과 실행본 플레이 통과는 별도로 기록한다.

## 사용자 승인 요청

다음 추천안을 한 묶음으로 승인받는다.

1. 첫 구현은 **1단계만** 진행한다.
2. 기술 샘플은 보존하고 별도 `RatHost2DPrototype.unity`를 만든다.
3. 기존 차원 독립 상태·테스트를 재사용하고 3D 결합부만 2D로 교체한다.
4. 시간 경과 기본 면역 상승은 `0`을 유지하고 위험 행동으로 자연 100%에 도달한다.
5. 2단계는 백혈구 회피형 1종만 이관하고 면역 신호 억제형은 보류한다.
6. 3단계에서 잠복 강화가 위험 행동 경계도 상승량에도 `0.55` 배율을 적용한다.
7. 기존 3D 씬과 2D 기술 샘플은 전체 루프 수용 후에도 별도 정리 승인 전까지 보존한다.
8. 위 원칙 승인 후 별도 구현 작업 패킷을 만들고 Unity 코드·씬·테스트 작업을 시작한다.

5번 승인 시 1~2단계의 자연 100% 경로는 `ContaminationExposure → WhiteBloodCellEvasion`으로 제한한다. 소음 배관·강제 조종 면역 트리거는 삭제하지 않고, 신호 억제 이관 또는 원인 라우팅 변경을 별도 승인할 때까지 기존 3D 레거시에만 유지한다.
