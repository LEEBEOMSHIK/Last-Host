# 캐릭터 비주얼 기준

이 폴더는 `마지막 숙주 / The Last Host`의 캐릭터별 승인 외형과 실제 게임 에셋으로 재설계할 때 지켜야 할 불변식을 기록한다. 콘셉트 이미지와 기준 문서는 제작 계약의 입력이며, 방향별 스프라이트·애니메이션·Unity 적용본을 자동으로 승인하지 않는다.

## 현재 문서

- `base-bacteriophage-character.md`: 가장 기본 바이러스인 박테리오파지의 외형, 성격, 업그레이드 불변식과 2D 아이소메트릭 도트 재설계 경계.

## 적용 규칙

1. 캐릭터 reference의 표현 방식과 실제 게임 제작 방식을 구분한다.
2. 실제 제작 전 방향 수, 프레임, 픽셀 규격, 피벗, 축소 가독성을 별도 승인·검증한다.
3. 특정 회사·캐릭터·작가의 스타일 모사를 제작 지시로 승계하지 않는다.
