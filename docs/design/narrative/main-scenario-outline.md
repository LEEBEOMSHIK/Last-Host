# 마지막 숙주 메인 시나리오·화면 흐름 초안

## 1. 문서 목적과 효력

이 문서는 `마지막 숙주 / The Last Host`를 처음 실행한 순간부터 엔딩 이후까지 이어지는 전체 플레이 경험을 한 파일에서 검토하기 위한 **상위 시나리오 초안**이다. 이야기만 나열하지 않고, 각 구간에서 플레이어가 실제로 보는 화면, 하는 행동, 배우는 시스템, 필요한 연출, 다음 구간으로 넘어가는 조건을 함께 제시한다.

이 문서는 현재 기획 요약과 쥐 숙주 프로토타입 문서를 연결한 **현재 작업 해석본**이다. 원본 초안을 대체하거나 전체 캠페인의 구현을 승인하지 않는다. 특히 벌레 튜토리얼, 전체 숙주 체인, 인간 숙주, 병원, 연구소, 백신, 다섯 엔딩은 사용자가 내용을 보완하고 별도로 승인해야 하는 장기 설계 영역이다.

## 2. 상태 표기

| 표기 | 의미 |
| --- | --- |
| **[확정 방향]** | 프로젝트 전반에 승인된 방향. 현재는 2D 아이소메트릭/쿼터뷰 도트 표현이 해당한다. |
| **[프로토타입 승인 범위]** | 쥐 숙주 수직 슬라이스에서 구현·검증하도록 승인된 범위. 정식 캠페인의 확정 설정을 뜻하지 않는다. |
| **[장기 제안 초안]** | 전체 게임을 논의하기 위한 서사·화면·시스템 제안. 구현 미승인이며 변경 가능하다. |
| **[미정]** | 플레이 규칙, 수치, 순서, 명칭 또는 결말 조건에 사용자 결정이 필요한 항목. |

이하에서 별도 표기가 없는 전체 캠페인 내용은 **[장기 제안 초안]**으로 본다.

## 3. 전체 경험의 한 줄 흐름

> 아주 약한 바이러스가 작은 생물의 몸에서 생존법을 배우고, 여러 숙주와 인간의 통제 공간을 거치며 변이한다. 플레이어는 매 순간 더 빠른 전이, 더 강한 지배, 더 오래가는 공존 중 무엇을 택할지 결정하고, 그 누적 결과로 슈퍼바이러스·지배·공존·사멸·수용 중 하나의 결말을 맞는다.

전체 캠페인의 제안 흐름은 다음과 같다.

1. 첫 실행과 접근성·표시 설정
2. 타이틀과 새 게임
3. 짧은 도입 연출
4. 벌레 숙주 튜토리얼
5. 첫 면역 반응과 내부 바이러스 튜토리얼
6. 첫 변이와 숙주 복귀
7. 자연 생태계의 숙주 전이
8. 쥐 숙주·도시 하수도 수직 슬라이스에 해당하는 중반 구간
9. 주택가와 인간 생활권 진입
10. 인간 숙주·병원·연구소·백신 대응
11. 마지막 선택과 다섯 엔딩
12. 결과 화면과 다음 플레이

**[중요]** 위 순서는 정식 캠페인 후보다. 현재 구현이 승인된 것은 이 중 `쥐 숙주·도시 하수도`에서 핵심 루프를 검증하는 수직 슬라이스뿐이다.

## 4. 공통 화면 언어와 조작 안내

### 4.1 비주얼과 카메라

- **[확정 방향]** 환경, 숙주, 바이러스, 백혈구, 효과는 2D 아이소메트릭/쿼터뷰 도트로 표현한다.
- **[확정 방향]** 숙주 탐험은 고정 아이소메트릭/쿼터뷰 카메라, 2D 충돌, 가림, Y축 깊이 정렬을 사용한다.
- **[프로토타입 승인 범위]** 내부 바이러스 모드는 작은 아레나에서 바이러스를 직접 움직이고 백혈구를 피하며 변이 조각을 수집한다.
- **[장기 제안 초안]** 캠페인에서도 두 모드의 이동 방향과 버튼 배치를 가능한 한 일치시켜 모드 전환 때 조작을 다시 배우지 않게 한다.

### 4.2 PC 기본 조작

| 입력 | 쥐 프로토타입 상태 | 장기 캠페인 제안 |
| --- | --- | --- |
| `WASD` | **[프로토타입 승인 범위]** 이동 | 모든 숙주와 내부 바이러스의 기본 이동 |
| `Space` | **[프로토타입 승인 범위]** 상호작용 | 조사, 섭취, 은신처 진입, 전이 시도 등 문맥 행동 |
| `Esc` | **[장기 제안 초안]** 일시정지 | 설정, 조작표, 현재 목표, 게임 종료 |
| 마우스 또는 방향키+확인 | **[장기 제안 초안]** | 변이 카드와 메뉴 선택 |

### 4.3 숙주 탐험 화면과 HUD

실제 플레이 화면은 숙주와 주변 환경을 중앙에 크게 두고, 정보는 가장자리로 밀어 시야를 확보한다.

| 위치 | 쥐 프로토타입 화면 구성 | 장기 캠페인 확장 제안 |
| --- | --- | --- |
| 좌측 상단 | 숙주 생명력, 면역 경계도 | 침식도 또는 공존도를 상황에 따라 추가 |
| 상단 중앙 | 현재 모드 또는 짧은 목표 | 스테이지 목표, 전이 후보 방향, 긴급 경고 |
| 우측 상단 | 최소 표시 또는 생략 | 인간 위험도, 백신 개발도는 해당 구간에서만 표시 |
| 화면 중앙 근처 | `Space` 상호작용 안내 | 대상 이름, 위험·전이 가능 여부 |
| 하단 | 현재 변이 효과 요약 | 숙주 경험 특성, 활성 변이 슬롯 |

- **[프로토타입 승인 범위]** 쥐 구간의 최소 게이지는 숙주 생명력과 면역 경계도다. `현재 모드` 표시는 화면 이해를 돕기 위한 **[장기 제안 초안]**이며 별도 확정이 필요하다.
- **[장기 제안 초안]** 아직 의미가 없는 게이지는 처음부터 모두 노출하지 않고, 관련 사건이 발생할 때 하나씩 개방한다.
- **[장기 제안 초안]** 게이지가 오를 때는 색 변화만 쓰지 않고 아이콘, 진동 또는 짧은 효과음, 한 줄 원인 문구를 함께 사용한다.

### 4.4 내부 바이러스 화면과 HUD

| 위치 | 표시 내용 |
| --- | --- |
| 좌측 상단 | 바이러스 안정도 또는 체력 |
| 상단 중앙 | 변이 조각 `현재/목표`, 필요한 경우 제한 시간 |
| 우측 상단 | 면역 포착 누적 또는 현재 위험 단계 |
| 화면 중앙 | 바이러스, 백혈구, 조각, 위험 패턴 |
| 하단 | 첫 진입 때만 이동·목표 안내, 이후에는 짧은 목표 문구 |

- **[프로토타입 승인 범위]** 백혈구 회피, 변이 조각 수집, 성공과 실패 결과를 제공한다.
- **[프로토타입 승인 범위]** 백혈구 접촉은 `면역 포착 +8` 흔적을 남기며, 성공하더라도 쥐 숙주 복귀 경계도에 부담이 누적된다.
- **[미정]** 목표 조각 수, 제한 시간 사용 여부, 안정도 수치, 난이도 상승 규칙은 별도 확정이 필요하다.

### 4.5 변이 선택 화면

- 화면 중앙에 세 장의 변이 카드를 같은 비중으로 배치한다.
- 선택 전에는 현재 숙주 화면이 어둡게 멈추고, 선택 후에는 바이러스 실루엣이나 효과 아이콘이 짧게 변화한 뒤 숙주 탐험으로 돌아간다.
- **[프로토타입 승인 범위]** 쥐 구간의 선택지는 `잠복 강화`, `신경 조종`, `포유류 적응` 세 가지다.
- **[장기 제안 초안]** 캠페인에서는 변이가 전이·변이·조종·공존 경향을 누적하고 엔딩 조건에도 영향을 준다.

## 5. 처음부터 끝까지의 구간별 시나리오

### 5.1 구간 0 — 첫 실행과 기본 설정

**상태: [장기 제안 초안]**

- **플레이 화면**: 검은 화면 위에 작은 바이러스 실루엣과 로고가 나타난다. 이어서 언어, 화면 밝기, 픽셀 스케일, 전체 화면, 음량, 화면 흔들림·점멸 감소 옵션을 한 번에 정한다.
- **플레이어 행동**: 기본 설정을 확인하고 계속한다. 이후 설정 메뉴에서 다시 바꿀 수 있다.
- **시스템/튜토리얼**: 저장 데이터가 없으면 접근성 설정 뒤 타이틀로 이동한다. 저장 데이터가 있으면 평소에는 이 화면을 생략한다.
- **연출/대사 목적**: 게임이 생물학적 공포만을 내세우기보다 작고 친근한 바이러스의 시점에서 시작한다는 인상을 준다. 긴 설명이나 세계관 문장은 넣지 않는다.
- **완료/전환 조건**: 필수 항목을 확인하면 타이틀 화면으로 전환한다.

### 5.2 구간 1 — 타이틀과 시작 화면

**상태: [장기 제안 초안]**

- **플레이 화면**: 2D 아이소메트릭 도트로 표현된 어두운 생태계 단면을 배경으로 `마지막 숙주 / The Last Host` 로고를 표시한다. 배경 한구석의 작은 생물이 움직여 살아 있는 세계임을 보여준다.
- **플레이어 행동**: `새 게임`, `이어하기`, `설정`, `기록`, `종료` 중 하나를 선택한다. 최초 실행에서는 `이어하기`와 `기록`을 비활성화한다.
- **시스템/튜토리얼**: 새 게임 선택 시 난이도 또는 도움말 수준을 고르는 방안은 후보로 둔다. 난이도 체계 자체는 **[미정]**이다.
- **연출/대사 목적**: 제목의 ‘마지막 숙주’가 누구인지 즉시 설명하지 않고 질문으로 남긴다. 엔딩을 본 뒤에는 선택 결과에 따라 배경의 생태나 바이러스 흔적이 조금 달라지는 방안을 제안한다.
- **완료/전환 조건**: `새 게임`을 확인하면 짧은 도입 연출로 이동한다. `이어하기`는 마지막 안전 지점 또는 진행 중 런으로 복귀한다.

### 5.3 구간 2 — 도입: 가장 작은 생존자

**상태: [장기 제안 초안]**

- **플레이 화면**: 물방울, 흙, 썩은 잎이 이어진 숲 바닥을 짧게 훑은 뒤, 미세한 세계로 확대해 기본 바이러스의 실루엣을 보여준다.
- **플레이어 행동**: 도입 중에는 이동하지 않는다. 한 번 본 뒤에는 건너뛸 수 있다.
- **시스템/튜토리얼**: 조작 설명을 아직 띄우지 않는다. 컷신 종료 직후 바로 플레이 가능한 벌레 숙주 화면으로 연결한다.
- **연출/대사 목적**: “세상은 가장 강한 것만을 위해 존재하지 않는다. 살아남는 방식은 하나가 아니다.”라는 메시지를 1~2문장 내의 내레이션 또는 무언 연출로 전달한다. 정확한 화자와 문구는 **[미정]**이다.
- **완료/전환 조건**: 바이러스가 벌레 숙주 내부에 자리 잡는 순간 화면의 미세 구조가 바깥 숲 바닥 타일맵으로 이어진다.

필요 최소 컷신으로 10~20초를 권장한다. 기본 바이러스의 기원, 이름, 자아 형성 과정을 길게 설명하지 않고 플레이 중 발견하게 한다.

### 5.4 구간 3 — 벌레 숙주 이동 튜토리얼

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 숲 바닥의 작은 안전 구역. 벌레 숙주 주변에 잎, 돌, 물방울, 먹이, 포식자 그림자가 배치된다. HUD에는 숙주 생명력만 먼저 보인다.
- **플레이어 행동**: `WASD`로 이동하고, 빛나는 먹이 또는 은신처 앞에서 `Space`를 눌러 상호작용한다.
- **시스템/튜토리얼**: 첫 입력 전에는 네 방향 이동 안내를 보여주고, 실제로 움직이면 즉시 사라진다. 이어서 한 번의 상호작용, 위험 구역 회피, 은신처 진입을 순서대로 학습한다. 설명창을 연속으로 띄우지 않고 행동 직전에 한 항목만 안내한다.
- **연출/대사 목적**: 플레이어가 바이러스 자체가 아니라 감염된 숙주를 조종하고 있음을 자연스럽게 이해시킨다. 벌레는 빠르지만 약하고, 작은 환경 변화도 위협이 된다는 감각을 준다.
- **완료/전환 조건**: 이동, 상호작용, 위험 회피를 각각 한 번 수행하고 첫 안전 지점에 도착하면 면역 경계도 시스템을 개방한다.

### 5.5 구간 4 — 면역 경계도 첫 학습

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 벌레가 먹이를 과하게 섭취하거나 위험한 행동을 한 뒤 화면 가장자리에 미세한 맥동이 생긴다. 좌측 상단에 `면역 경계도`가 처음 나타난다.
- **플레이어 행동**: 안전하게 이동하면 경계도 상승이 완만하고, 위험 행동을 반복하면 빠르게 오르는 차이를 체험한다.
- **시스템/튜토리얼**: 최초 상승 때 `숙주가 이상을 감지합니다`와 원인 아이콘을 표시한다. 50% 부근에서 내부 반응이 가까워졌음을 예고하고, 100%에서 이동 입력을 잠시 유지한 채 전환 연출로 들어간다.
- **연출/대사 목적**: 면역 경계도를 단순 시간제한이 아니라 플레이 방식에 대한 숙주의 반응으로 이해시킨다.
- **완료/전환 조건**: 면역 경계도 100% 도달 시 첫 내부 바이러스 모드로 전환한다.

### 5.6 구간 5 — 첫 내부 바이러스 튜토리얼

**상태: [장기 제안 초안]. 구조는 쥐 프로토타입의 승인된 핵심 루프를 캠페인 도입에 재배치한 제안이다.**

- **플레이 화면**: 숙주 외부 화면이 색과 소리로 압축되며 작은 내부 아레나로 이어진다. 바이러스, 느린 백혈구 1종, 가까운 변이 조각부터 차례로 나타난다.
- **플레이어 행동**: 동일한 `WASD` 이동으로 조각을 줍고 백혈구를 피한다. 첫 조각은 위험 없이 획득하고, 이후 백혈구가 진입한다.
- **시스템/튜토리얼**: 바이러스 안정도, 조각 수, 접촉 위험을 순서대로 공개한다. 첫 접촉은 즉시 실패시키지 않고 손실과 면역 포착의 의미를 알려준다.
- **연출/대사 목적**: 숙주 바깥의 탐험과 숙주 안의 생존이 하나의 몸에서 연결되어 있음을 보여준다. 전환은 벌이 아니라 ‘바이러스가 반드시 감당해야 하는 내부 압박’으로 느껴져야 한다.
- **완료/전환 조건**: 바이러스 안정도가 0이 되기 전에 목표 조각을 모으면 성공한다. 실패하면 짧은 실패 학습 화면 뒤 같은 튜토리얼을 다시 시도하거나 완화된 조건으로 재도전하는 방안을 제안한다. 정확한 튜토리얼 실패 처리 방식은 **[미정]**이다.

### 5.7 구간 6 — 첫 변이와 숙주 복귀

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 세 장의 간단한 변이 카드가 나타난다. 카드 위에 전이·조종·공존 등 장기 경향을 상징하는 아이콘을 붙인다.
- **플레이어 행동**: 한 가지 변이를 선택하고, 숙주 화면으로 돌아가 효과를 직접 시험한다.
- **시스템/튜토리얼**: 첫 선택에서는 숫자보다 플레이 변화가 명확한 효과를 제공한다. 복귀 직후 20~30초 안에 선택 효과를 확인할 수 있는 장애물이나 안전 경로를 배치한다.
- **연출/대사 목적**: 변이는 단순 능력치 상승이 아니라 바이러스가 ‘어떤 생존 방식을 택하는가’를 쌓는 결정임을 처음 알린다.
- **완료/전환 조건**: 변이 효과를 한 번 발동하거나 관련 행동을 수행하면 첫 숙주 전이 목표가 열린다.

### 5.8 구간 7 — 첫 숙주 전이

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 현재 숙주가 접근할 수 있는 환경 안에 다음 숙주 후보의 흔적을 먼저 보여준다. 직접적인 화살표 대신 발자국, 체온, 먹이 활동, 접촉 지점을 강조한다.
- **플레이어 행동**: 후보를 관찰하고 전이 조건을 만든 뒤 `Space`로 전이를 시도한다. 예를 들어 먹이사슬 접촉, 흡혈, 상처, 배설물, 가까운 생활권 접촉 중 숙주에 맞는 방식을 사용한다.
- **시스템/튜토리얼**: 후보마다 전이 가능성, 현재 변이와의 적합도, 실패 위험을 간단한 아이콘으로 보여준다. 첫 전이는 정답 경로 하나를 명확히 제공하고 이후부터 선택지를 늘린다.
- **연출/대사 목적**: 숙주 전이는 맵 출구가 아니라 생태 관계를 이용하는 행위임을 보여준다. 4~6초 정도의 인게임 확대·교차 전환만 사용하고 긴 컷신은 피한다.
- **완료/전환 조건**: 전이 조건을 충족하면 새 숙주의 짧은 내부 적응 구간을 거쳐 다음 스테이지로 이동한다. 실패하면 현재 숙주에 남고 면역 또는 환경 위험이 증가한다.

새 숙주로 갈 때 이전 숙주의 특성 중 무엇을 얼마나 가져갈지는 **[미정]**이며, 변이와 숙주 경험 특성은 별도 체계로 유지한다.

### 5.9 구간 8 — 자연 생태계 전반부

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 숲 바닥에서 연못과 풀숲으로 공간이 넓어진다. 벌레와 모기 등 작은 숙주는 좁은 틈, 수면 가장자리, 식생 위를 이용한다.
- **플레이어 행동**: 숙주별 이동 차이를 배우고, 생존 자원을 찾고, 전이 후보를 추적하며, 필요할 때 내부 면역 반응을 돌파한다.
- **시스템/튜토리얼**: 숙주가 바뀔 때마다 새 조작을 모두 다시 설명하지 않는다. 기존 조작 위에 `이 숙주만의 행동` 한 가지씩을 추가한다. 변이·조종·공존 경향의 누적 결과를 첫 스테이지 종료 화면에서 요약한다.
- **연출/대사 목적**: 자연 생태계에서는 바이러스가 절대적인 악이나 주인이 아니라 먹이사슬과 환경 변화 속의 작은 생존자로 보이게 한다.
- **완료/전환 조건**: 농장 또는 도시로 이어지는 전이 조건을 충족하면 인간 생활권의 흔적이 처음 보인다.

예상 연결은 `벌레 → 모기 → 새 또는 소형 포유류`이지만, 정확한 숙주 순서와 필수·선택 숙주 구분은 **[미정]**이다.

### 5.10 구간 9 — 농장: 인간 활동의 첫 압력

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 자연 타일과 울타리, 사료, 축사, 배수로, 인공 조명이 섞인다. 인간은 거대한 실루엣, 발소리, 도구의 움직임으로 먼저 존재감을 드러낸다.
- **플레이어 행동**: 야생 숙주, 새, 가축 중 가능한 전이 경로를 찾고 인간 활동 시간을 피해 이동한다.
- **시스템/튜토리얼**: `인간 위험도`를 이 구간에서 처음 여는 방안을 제안한다. 눈에 띄는 감염 행동이나 숙주 피해가 크면 위험도가 오르고, 잠복·공존 행동은 상승을 늦춘다.
- **연출/대사 목적**: 인간을 곧바로 최종 적으로 규정하지 않는다. 인간의 방역은 자신의 생태를 지키려는 반응이며, 플레이어의 행동이 그 대응 강도를 바꾼다는 관계를 만든다.
- **완료/전환 조건**: 배수로, 운송 수단, 먹이사슬 중 하나를 이용해 도시 하수도 또는 주택가로 전이한다.

### 5.11 구간 10 — 도시 하수도와 쥐 숙주

**상태: 캠페인 위치는 [장기 제안 초안], 쥐 수직 슬라이스의 핵심 루프는 [프로토타입 승인 범위]**

- **플레이 화면**: 작은 2D 아이소메트릭 하수도 맵. 쥐, 배관, 물길, 위험 요소, 막힌 경로와 관심 지점이 보인다. HUD에는 승인된 최소 게이지인 숙주 생명력과 면역 경계도가 표시되며, `현재 모드` 표시는 **[장기 제안 초안]**이다.
- **플레이어 행동**: `WASD`로 쥐를 움직이고 `Space`로 관심 지점과 상호작용한다. 시간 경과 또는 위험 행동으로 면역 경계도가 오르고, 100%가 되면 내부 모드에 진입한다.
- **시스템/튜토리얼**: 캠페인에서는 앞서 배운 시스템을 재설명하지 않고 쥐 특유의 빠른 지상 이동과 통로 접근만 안내한다. 수직 슬라이스 단독 빌드에서는 이 구간이 첫 플레이이므로 6장의 짧은 안내 순서를 사용한다: 이동 → 상호작용 → 생명력 → 면역 경계도 → 내부 목표 → 변이 효과.
- **연출/대사 목적**: 자연 환경에서 인간 생활권으로 넘어가는 중간 지점이자, 작은 숙주보다 넓은 이동 자유와 더 복잡한 면역 압박을 동시에 체감하게 한다.
- **완료/전환 조건**: 프로토타입에서는 내부 미니게임 성공 또는 실패 후 변이 적용 여부를 반영해 쥐 조종으로 복귀하면 핵심 루프 1회가 완료된다. 캠페인에서는 특정 통로, 먹이, 접촉 지점을 통해 주택가 숙주 후보로 전이해야 구간이 끝난다.

쥐 프로토타입의 정확한 단독 흐름은 6장에서 별도로 정리한다.

### 5.12 구간 11 — 주택가: 관계와 선택의 확대

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 골목, 배수구, 정원, 실내 가장자리로 구성된 생활권. 고양이와 개 같은 동물, 인간의 생활 흔적, 방역 물품이 동시에 보인다.
- **플레이어 행동**: 공격적인 전이, 은밀한 잠복, 숙주를 덜 해치는 공존 행동 중 하나를 반복적으로 선택한다. 고양이·개를 필수 숙주로 만들지, 선택 경로로 둘지는 **[미정]**이다.
- **시스템/튜토리얼**: 침식도와 공존도 중 적어도 하나를 이 시점에 명시적으로 보여주는 방안을 제안한다. 숫자만 바뀌지 않고 숙주 애니메이션, 이동 안정성, 면역 상승 속도, 주변 반응이 달라져야 한다.
- **연출/대사 목적**: 숙주가 단순 탈것이 아니라 피해를 입거나 바이러스와 균형을 이루는 생명임을 부각한다. 플레이어가 앞선 선택의 윤리적·기계적 결과를 처음 분명히 보게 한다.
- **완료/전환 조건**: 인간에게 접근할 수 있는 감염 경로를 확보하거나, 인간을 피하고 동물 숙주 사이에서 장기 생존하는 선택을 하면 후반 분기가 열린다.

### 5.13 구간 12 — 인간 숙주 진입

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 인간을 외부에서 직접 조종하는 방식, 신체 내부만 다루는 방식, 제한된 행동 선택 방식 중 하나가 필요하다. 현재는 **[미정]**이다.
- **플레이어 행동**: 인간 숙주에 진입한 경우 일상 행동을 이용해 이동·전이를 시도하거나, 증상을 억제하고 검사망을 피하거나, 의도적으로 통제력을 높인다.
- **시스템/튜토리얼**: 인간 위험도와 사회적 탐지, 의료 검사, 숙주 의지 저항을 단계적으로 소개한다. 인간 조종이 기존 동물 조종보다 지나치게 복잡해지지 않도록 핵심 행동 수를 제한한다.
- **연출/대사 목적**: 인간을 ‘최종 상위 숙주’로만 보지 않고, 자신이 통제한다고 믿지만 생태계와 미생물에 의존하는 약한 존재라는 메시지를 드러낸다.
- **완료/전환 조건**: 증상 악화, 자발적 검사, 사고, 전이 성공 등의 사건을 통해 병원 구간으로 들어간다. 인간을 피한 경로는 병원 대신 별도의 공존·생태 분기로 이어질 수 있다.

### 5.14 구간 13 — 병원: 관찰당하는 바이러스

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 병실, 복도, 검사실, 격리 구역을 2D 아이소메트릭 도트로 표현한다. 이전의 자연색은 줄고 차가운 인공 조명과 경고 표시가 늘어난다.
- **플레이어 행동**: 숙주를 이동시키고, 검사와 투약을 피하거나 받아들이며, 다른 숙주로 전이할지 현재 숙주 안에서 잠복할지 선택한다.
- **시스템/튜토리얼**: `백신 개발도` 또는 연구 진척을 처음 표시하는 후보 구간이다. 무차별 전이는 개발도를 빠르게 올리고, 잠복과 공존은 시간을 벌지만 성장 기회를 줄이는 식의 상충 관계를 제안한다.
- **연출/대사 목적**: 인간의 의료 대응을 단순 장애물이 아니라 플레이어의 확산과 피해에 대한 결과로 보여준다. 의료진 개인을 악역으로 고정하지 않는다.
- **완료/전환 조건**: 검체가 연구소로 이동하거나, 숙주가 격리되거나, 플레이어가 병원을 탈출하면서 연구소·도시 확산·잠복 생존 중 하나의 후반 경로가 열린다.

### 5.15 구간 14 — 연구소: 생존 방식의 최종 시험

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 연구 장비, 배양 구역, 격리 용기, 데이터 화면이 보이는 최종 스테이지. 외부 숙주 탐험과 내부 바이러스 아레나를 짧은 간격으로 교차하는 구성을 제안한다.
- **플레이어 행동**: 백신 샘플을 파괴하거나 적응에 이용하고, 숙주 통제력을 극대화하거나, 연구자에게 자신의 존재를 드러내거나, 확산을 멈추는 선택을 한다.
- **시스템/튜토리얼**: 새 핵심 시스템을 추가하지 않는다. 전이·변이·조종·공존, 인간 위험도, 백신 개발도 등 지금까지 배운 결과를 한곳에서 결산한다.
- **연출/대사 목적**: 최종 갈등을 ‘백신을 이기면 승리’로 단순화하지 않는다. 바이러스가 살아남기 위해 무엇을 포기했고 숙주와 생태에 무엇을 남겼는지를 묻는다.
- **완료/전환 조건**: 누적 경향과 마지막 행동이 결합되어 다섯 엔딩 중 하나로 진입한다. 엔딩 우선순위와 수치 조건은 **[미정]**이다.

### 5.16 구간 15 — 마지막 선택

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 최종 상황을 인게임 화면으로 유지한 채 2~3개의 문맥 행동을 제시한다. 별도의 텍스트 선택지만 띄우기보다 실제 위치 이동이나 상호작용으로 선택하게 한다.
- **플레이어 행동**: 마지막 전이, 백신 대응, 숙주 통제 해제 또는 강화, 자발적 노출·정지 중 가능한 행동을 선택한다.
- **시스템/튜토리얼**: 각 선택이 어떤 엔딩을 보장하는지 직접 이름으로 공개하지 않는다. 대신 지금까지 쌓은 경향과 충돌하면 경고를 주고, 되돌릴 수 없는 선택임을 확인한다.
- **연출/대사 목적**: 마지막 한 번의 버튼이 전체 플레이를 무효화하지 않게 한다. 결말은 누적된 생존 방식이 마지막 행동을 통해 확정되는 구조여야 한다.
- **완료/전환 조건**: 선택 확정 후 저장하고, 20~40초 내외의 엔딩 연출과 후일담으로 이동한다.

### 5.17 구간 16 — 엔딩 후 흐름

**상태: [장기 제안 초안, 구현 미승인]**

- **플레이 화면**: 엔딩 연출 뒤 결과 화면에서 이동한 숙주, 핵심 변이, 주요 선택, 인간 위험도·백신 개발도 변화, 도달한 엔딩을 시간선 형태로 보여준다.
- **플레이어 행동**: `기록 보기`, `타이틀로`, `새 게임`, 조건을 충족한 경우 `분기 지점부터 검토` 중 하나를 선택한다.
- **시스템/튜토리얼**: 엔딩 도감은 본 엔딩의 명칭과 짧은 해설만 공개하고, 보지 않은 엔딩은 실루엣과 모호한 힌트만 보여준다. 영구 성장이나 새 게임+는 현재 확정하지 않는다.
- **연출/대사 목적**: 성공·실패 이분법보다 플레이어가 선택한 생존 방식의 결과를 돌아보게 한다. 사멸 엔딩도 단순 게임 오버가 아니라 하나의 완결된 결말로 취급한다.
- **완료/전환 조건**: 타이틀로 돌아가거나 새 게임을 시작한다. 이어하기 슬롯은 엔딩 직전이 아니라 결과 기록 상태로 보존해 엔딩 연출을 반복 확인할 수 있게 하는 방안을 제안한다.

## 6. 쥐 숙주 프로토타입 단독 플레이 흐름

이 절은 전체 캠페인과 분리된 **현재 승인 수직 슬라이스**를 설명한다. 쥐부터 시작하는 것이 정식 캠페인 순서라는 뜻은 아니다. 화면 배치와 안내 문구는 검토용 제안이며, 승인된 핵심 범위를 바꾸지 않는다.

### 6.1 프로토타입 시작

- **플레이 화면**: 짧은 제목 카드 뒤 하수도 쥐 숙주 화면으로 바로 진입한다.
- **플레이어 행동**: `WASD`로 이동한다.
- **시스템/튜토리얼**: 첫 이동 후 `WASD 이동` 안내를 제거하고, 관심 지점 가까이에서 `Space 상호작용`을 안내한다. 숙주 생명력과 면역 경계도의 의미를 각각 처음 변할 때 설명한다.
- **연출/대사 목적**: 설정 설명보다 조작과 핵심 루프 검증을 우선한다. 전체 캠페인의 도입 컷신이나 벌레 튜토리얼을 끌어오지 않는다.
- **완료/전환 조건**: 플레이어가 이동과 상호작용을 한 번씩 수행하면 자유 탐색 상태가 된다.

### 6.2 하수도 탐색과 경계도 상승

- **플레이 화면**: 작은 하수도 맵, 위험 요소 1~2개, 막힌 경로 또는 관심 지점이 보인다.
- **플레이어 행동**: 지형을 탐색하고 위험 요소를 피하거나 감수한다.
- **시스템/튜토리얼**: 시간 경과 또는 위험 행동으로 면역 경계도가 오른다. 상승 원인을 짧은 피드백으로 알리고 100% 도달을 예고한다.
- **연출/대사 목적**: 쥐 조작의 재미와 면역 압박의 관계를 별도 설명 없이 체감시킨다.
- **완료/전환 조건**: 면역 경계도 100%에서 내부 바이러스 모드로 전환한다.

### 6.3 내부 바이러스 미니게임

- **플레이 화면**: 작은 내부 아레나, 바이러스, 백혈구 1종, 변이 조각, 바이러스 안정도와 조각 수 HUD를 표시한다.
- **플레이어 행동**: 바이러스를 이동해 백혈구를 피하고 목표 조각을 모은다.
- **시스템/튜토리얼**: 백혈구 접촉 시 안정도가 감소하고 `면역 포착 +8` 흔적이 누적된다. 정확한 목표 수량과 제한 조건은 현재 조정 가능한 값이다.
- **연출/대사 목적**: 외부 탐험의 경계도 상승이 내부 생존 압박으로 이어진다는 인과를 분명히 한다.
- **완료/전환 조건**: 안정도 0 이전에 목표 조각을 모으면 성공, 안정도 0이면 실패다.

### 6.4 성공과 변이 선택

- **플레이 화면**: 성공 표시 후 `잠복 강화`, `신경 조종`, `포유류 적응` 세 카드가 나타난다.
- **플레이어 행동**: 한 가지를 선택한다.
- **시스템/튜토리얼**: `잠복 강화`는 면역 경계도 상승 속도를 낮추고, `신경 조종`은 조종력과 이동 속도를 높이며, `포유류 적응`은 프로토타입 안에서 특정 통로 접근을 허용한다. 면역 포착 흔적이 있으면 복귀 경계도에 누적한다.
- **연출/대사 목적**: 보상이 숙주 탐험을 실제로 바꾼다는 점을 즉시 이해시키는 데 집중한다.
- **완료/전환 조건**: 변이를 확정하면 쥐 숙주 모드로 복귀하고, 새 효과를 확인할 수 있는 상태가 된다.

### 6.5 실패와 복귀

- **플레이 화면**: `면역 반응 돌파 실패` 임시 제목과 실패 원인, `쥐 숙주로 복귀` 안내를 표시한다.
- **플레이어 행동**: 확인 입력으로 복귀한다.
- **시스템/튜토리얼**: 변이 보상을 주지 않는다. 성공 복귀보다 높은 면역 경계도를 남겨 다음 내부 대응 압박을 유지한다.
- **연출/대사 목적**: 한 번의 미니게임 실패가 곧 전체 런 종료는 아니지만, 아무 비용 없는 재시도도 아니라는 점을 전달한다.
- **완료/전환 조건**: 확인 후 쥐 숙주 모드로 돌아간다. 프로토타입에서 숙주 생명력 0, 전체 재시작, 체크포인트를 어떻게 처리할지는 **[미정]**이다.

### 6.6 루프 완료 표시

- **플레이 화면**: 성공 복귀 시 선택한 변이와 변화한 수치를 짧게 강조한다. 실패 복귀 시 높아진 압박을 강조한다.
- **플레이어 행동**: 계속 탐색하며 변이 효과 또는 실패 부담을 체감한다.
- **시스템/튜토리얼**: 별도 설명 없이 20~30초 내에 변화가 드러나는 상황을 제공한다.
- **연출/대사 목적**: `탐험 → 면역 반응 → 내부 생존 → 보상 또는 부담 → 탐험 복귀`가 하나의 반복 가능한 루프로 느껴지는지 검증한다.
- **완료/전환 조건**: 플레이테스트 기준에서는 변이 효과를 확인하거나 실패 후 재압박을 확인하면 1회 검증 흐름이 완료된다.

## 8. 장기 분기 구조

전체 분기는 선악 선택지보다 플레이 방식의 누적으로 형성하는 방안을 제안한다.

| 경향 | 주로 쌓이는 행동 | 플레이 변화 제안 | 주된 엔딩 연관 |
| --- | --- | --- | --- |
| 전이 | 새 숙주 탐색, 전이 위험 감수, 환경 적응 | 전이 후보와 지역 접근 증가 | 슈퍼바이러스 또는 공존 |
| 변이 | 내부 미니게임 적극 공략, 백신 대응 선택 | 면역·백신 대응력 증가 | 슈퍼바이러스 |
| 조종 | 숙주 의지 억압, 강제 이동·확산 | 강한 직접 통제, 숙주 부담 증가 | 지배 |
| 공존 | 숙주 손상 억제, 잠복, 제한적 증식 | 면역 압박 감소, 성장 속도 완화 | 공존 또는 수용 |
| 포기·소진 | 무리한 확산 실패, 자발적 증식 중단 | 전이 능력 축소 또는 생존 종료 | 사멸 또는 수용 |

정확한 변수, 공개 여부, 엔딩 우선순위, 되돌릴 수 있는 선택의 범위는 모두 **[미정]**이다.

## 9. 다섯 엔딩 초안

다섯 엔딩은 모두 **[장기 제안 초안, 구현 미승인]**이다. 아래 조건은 토론용 방향이며 확정 규칙이 아니다.

### 9.1 슈퍼바이러스 엔딩

- **도달 경향 제안**: 높은 변이·전이 적응, 높은 백신 대응력, 연구소의 최종 대응 돌파.
- **마지막 행동 제안**: 백신 샘플을 분석·흡수해 새로운 환경으로 확산한다.
- **결과 연출**: 연구소의 봉쇄는 성공한 듯 보이지만 여러 생태권에서 같은 바이러스 신호가 나타난다.
- **핵심 의미**: 가장 강하게 적응했지만, 생존을 위해 끝없는 군비 경쟁을 선택했다.
- **엔딩 후 질문**: 끝없이 변해야만 하는 생존이 정말 승리인가?

### 9.2 지배 엔딩

- **도달 경향 제안**: 높은 조종·침식, 숙주 의지 억압, 강제 전이와 높은 인간 위험도.
- **마지막 행동 제안**: 핵심 인간 숙주 또는 네트워크를 완전히 장악해 확산 명령을 실행한다.
- **결과 연출**: 질서정연한 숙주들의 움직임 뒤로 개별 생명의 자율성이 사라진다.
- **핵심 의미**: 바이러스는 살아남고 강해졌지만, 숙주를 세계가 아닌 도구로만 남겼다.
- **엔딩 후 질문**: 모든 것을 통제한 존재는 무엇과 함께 살아가는가?

### 9.3 공존 엔딩

- **도달 경향 제안**: 높은 공존, 낮은 숙주 피해, 여러 생태권에서의 안정적 잠복, 통제 가능한 인간 위험도.
- **마지막 행동 제안**: 폭발적 확산이나 백신 파괴 대신 증식 속도를 낮추고 숙주와 장기 균형을 선택한다.
- **결과 연출**: 시간이 흐른 뒤 바이러스는 여러 숙주의 생태 안에 미세하게 남지만 대규모 파괴는 일어나지 않는다.
- **핵심 의미**: 지배하지 않아도 살아남을 수 있으며, 가장 오래가는 생존은 관계일 수 있다.
- **엔딩 후 질문**: 보이지 않는 공존도 하나의 완전한 삶인가?

### 9.4 사멸 엔딩

- **도달 경향 제안**: 바이러스 안정성 상실, 전이 단절, 백신·면역 대응 실패 또는 자발적 자기 소멸.
- **마지막 행동 제안**: 마지막 숙주를 살리기 위해 전이를 포기하거나, 끝까지 저항하다 제거된다.
- **결과 연출**: 바이러스의 신호가 사라진 뒤 숙주와 환경이 회복되거나 또 다른 미생물의 삶이 이어진다.
- **핵심 의미**: 개체의 사멸이 세계의 끝은 아니며, 실패와 희생을 구분해서 보여준다.
- **엔딩 후 질문**: 살아남지 못한 선택도 의미를 남길 수 있는가?

사멸을 일반 게임 오버와 같은 조건으로 둘지, 최종 구간의 완결 엔딩으로만 둘지는 **[미정]**이다.

### 9.5 수용 엔딩

- **도달 경향 제안**: 공존 또는 절제된 변이, 인간과의 접촉에서 낮은 피해, 연구소에서 자발적 노출 또는 협력 선택.
- **마지막 행동 제안**: 숨거나 지배하지 않고 자신의 존재와 한계를 드러내며, 인간도 완전 제거 대신 관리·관찰·공생을 선택한다.
- **결과 연출**: 격리 용기나 숙주 안에 남은 바이러스가 연구 대상이자 생태 구성원으로 인정되고, 인간 측도 통제할 수 없는 생명과 함께 사는 법을 배운다.
- **핵심 의미**: 공존이 생태적 균형이라면 수용은 서로의 존재를 의식적으로 인정하는 결말이다.
- **엔딩 후 질문**: 이해받기 위해 힘을 내려놓는 것은 패배인가, 다른 형태의 생존인가?

`공존`과 `수용`의 차이를 위와 같이 둘지, 다른 의미로 재정의할지는 사용자의 핵심 결정이 필요하다.

## 10. 인게임 연출과 컷신 사용 원칙

컷신의 프로젝트 기본 형식은 **픽셀아트 모션 코믹형 시네마틱**이다. 정지·분리 레이어, 제한 프레임, 카메라와 패럴랙스, 효과, 자막·오디오 큐를 조합하며 세부 제작·역할 인계 기준은 [픽셀아트 모션 코믹형 시네마틱 가이드](pixel-art-motion-comic-cinematic-guide.md)를 따른다. 이 형식의 확정은 장기 캠페인 장면의 실제 제작 승인을 뜻하지 않는다.

### 10.1 기본 원칙

1. 조작 가능한 장면에서 전달할 수 있는 사건은 인게임 연출로 처리한다.
2. 컷신은 픽셀아트 모션 코믹형 시네마틱을 기본으로 하되 플레이어 입력을 오래 빼앗지 않고, 첫 도입·중요 전이·결말에만 제한한다.
3. 도트 화면의 실제 플레이 크기에서 읽히는 실루엣, 조명, 움직임을 우선한다.
4. 바이러스의 감정은 긴 대사보다 짧은 몸짓, 효과음, 변이 카드 문구로 표현한다.
5. 생물학 용어 설명은 도감 또는 선택형 도움말로 보내고 핵심 흐름을 막지 않는다.
6. 실제 제작 전 숏·스토리보드·레이어·비최종 애니매틱 계획과 Unity 인계 명세를 먼저 검토한다.

### 10.2 최소 연출 목록 제안

| 연출 | 형식 | 권장 길이 | 상태 |
| --- | --- | --- | --- |
| 최초 도입 | 픽셀아트 모션 코믹형 시네마틱 | 10~20초 | 장기 제안, 구현 미승인 |
| 숙주 전이 | 인게임 확대·교차 | 4~6초 | 장기 제안 |
| 숙주→내부 전환 | 색·음향·줌 전환 | 1~2초 | 쥐 핵심 루프에 필요한 표현, 세부 미정 |
| 내부→변이 선택 | 짧은 정지·카드 전환 | 1~2초 | 쥐 핵심 루프에 필요한 표현, 세부 미정 |
| 인간 생활권 첫 진입 | 인게임 파노라마 | 5~8초 | 장기 제안 |
| 병원·연구소 진입 | 짧은 모션 코믹 또는 인게임 통제 연출 | 5~8초 | 장기 제안, 구현 미승인 |
| 엔딩 | 픽셀아트 모션 코믹형 시네마틱+후일담 | 20~40초 | 장기 제안, 구현 미승인 |

### 10.3 제작과 역할 경계

- 픽셀아트 시네마틱 연출 에이전트는 숏, 스토리보드, 레이어 분해 지시, 비최종 애니매틱 계획과 Unity 인계 명세를 담당한다.
- ChatGPT 이미지 아트 에이전트의 생성 결과는 장면·레이어 후보이며 최종 에셋이나 완성 컷신이 아니다.
- 사용자가 방향과 후보를 선택하고, 비주얼/테크아트가 픽셀 제작 적합성을 검토한 뒤, 별도 승인된 Unity 통합과 QA를 거친다.
- 실제 이미지·영상·애니매틱·오디오 제작과 Unity 반입은 개별 작업의 별도 승인 대상이다.

## 13. 승인 경계 요약

### 확정 사항

- 2D 아이소메트릭/쿼터뷰 도트 비주얼·공간 방향
- 작은 하수도 맵의 쥐 숙주 수직 슬라이스
- 쥐 이동, 관심 지점 상호작용, 숙주 생명력과 면역 경계도
- 면역 경계도 100%에서 내부 바이러스 모드 전환
- 바이러스 이동, 백혈구 1종 회피, 변이 조각 수집, 성공·실패
- 성공 시 세 가지 변이 선택, 실패 시 보상 없이 쥐 숙주로 복귀
- 변이 적용 후 쥐 숙주 플레이 복귀

### 장기 제안 초안이며 구현 미승인인 사항

- 벌레 숙주 도입과 전체 튜토리얼
- 모기·새·고양이·개·가축 등 전체 숙주 체인
- 숲 바닥부터 연구소까지의 정식 스테이지 진행
- 인간 숙주 플레이
- 병원·연구소·백신 개발 시스템
- 침식도·공존도·인간 위험도의 전체 캠페인 규칙
- 완성형 로그라이크 런, 저장, 체크포인트, 영구 성장
- 슈퍼바이러스·지배·공존·사멸·수용 엔딩과 엔딩 후 기능

### 다음 승인 전 금지 해석

- 이 문서를 근거로 전체 캠페인 구현이 승인되었다고 보지 않는다.
- 벌레 튜토리얼을 쥐 프로토타입의 선행 구현으로 자동 추가하지 않는다.
- 쥐 프로토타입이 정식 캠페인의 첫 스테이지라고 확정하지 않는다.
- 인간, 병원, 연구소, 백신, 엔딩 관련 Unity 씬·코드·에셋 제작을 시작하지 않는다.
