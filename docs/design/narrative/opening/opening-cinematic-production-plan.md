# 오프닝 시네마틱 제작 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to execute this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 승인된 오프닝·기원 설계를 픽셀아트 모션 코믹형 시네마틱, 커스터마이징과 첫 튜토리얼로 안전하게 발전시킨다.

**Architecture:** 사건·기원 계약, 씬 내용·문구·튜토리얼 선택, 숏·스토리보드와 결과 러닝타임 산정, 이미지 후보, 애니매틱·오디오, Unity 통합을 서로 독립된 승인 게이트로 나눈다. 앞 단계의 승인은 다음 단계의 제작 승인을 자동으로 포함하지 않는다.

**Tech Stack:** Markdown 기획 문서, 2D 아이소메트릭 도트, 픽셀아트 모션 코믹형 시네마틱, 향후 별도 승인 시 Unity `6000.4.6f1`·URP.

## Global Constraints

- 현재 실행 승인 범위는 문서 설계와 태스크 정리까지다.
- 주인공은 박테리오파지이며 인간 세포를 직접 감염하지 않는다.
- 청소 노동자는 감염의 원인이나 환자 0이 아니다.
- 생화학 무기의 구체적인 물질·유전자·배양·제조·전달 절차를 작성하거나 시각화하지 않는다.
- 생성 이미지는 후보이며 사용자 선택과 픽셀 적합성 검토 전에는 최종 에셋이 아니다.
- 쥐 숙주 프로토타입과 전체 캠페인 구현 범위를 자동 확대하지 않는다.
- 기존 미커밋 메인 시나리오·시네마틱 가이드 파일은 별도 동기화 승인 전 수정하지 않는다.

- [x] **Step 1:** 청소 노동자의 작업 공간을 `영업 종료 직전~심야의 복합 환승시설 청소 구역`으로 확정하고, 환승 통로→승강장 인접 공용구역→직원용 세척·배수 구역의 연결 동선을 사용한다. 정확한 숏·러닝타임·에셋·Unity 적용은 후속 승인 대상으로 둔다.
- [x] **Step 2:** 제작 기준 가안으로 `마감 동선 추적형 + 성실한 행동 한 비트`를 사용한다. 종료 안내·승객 감소 → 젖은 바닥 안내물로 통행 확보 → 정상 장갑·작업복 차림의 환승 통로 청소 → 카트를 승강장 인접 구역에서 직원 세척 구역으로 이동 → 밀대·도구 헹굼과 정돈 → 사람·작업물에서 고개를 돌린 짧은 기침 → 순간 무음·비말 확대 → 세균 군집·환경 미생물·여러 파지 중 주인공 식별 → 세척수 얕은 물막 → 격자 배수구·세균막 미세환경 순서로 연결한다. 핵심 소품은 카트·밀대, 정상 장갑·작업복, 젖은 바닥 안내물, 환기구, 세척통·세척대, 물막·격자 배수구로 제한하고, 파손 보호구·방치 오물·경고 무시 또는 미완료 체크·기침 뒤 새 감염 피해·인간 세포 감염 묘사는 금지한다. 주인공 고유 색·음향은 비말 내부 진입 후에만 시작한다. 스토리보드·결과물 검토 후 사용자 승인으로 수정할 수 있다.
- [x] **Step 3:** `레이어형 혼합` 커스터마이징으로 초기 색 6종·얼굴/표정 4종·캡시드 무늬 4종·짧고 둥근 spike 2종·자유 이름과 추천 이름·성격 강조점(호기심/용감/장난기)을 제공하고 능력치·변이 확률·엔딩 성향과 분리한다. 진행 중에는 추가 팔레트·표정·무늬·검증된 spike 장식·작은 배지·은은한 발광 흔적을 해금한다. 큰 캡시드, 짧은 2~3분절 몸, 두 팔·두 다리, 작은 꼬리와 짧고 둥근 spike를 고정하며, 팔다리 수·길이·꼬리 유무·과도하거나 날카로운 spike는 바꾸지 않는다. 방어구·결정·발광 코어·진화 spike는 성장 언어로 예약한다. 커스터마이징 전 장면은 확정 기본형을 선명하게 표시하고 확정 순간 실제 선택 외형으로 변화하며, 이후 모든 컷신·모션 코믹·인게임·메뉴·초상과 재시청·회상은 저장 슬롯의 현재 외형과 서사 시점 규칙을 따른다. 색·얼굴·무늬·spike 레이어 합성, spike 2종 제한과 모션 코믹 포즈 재사용을 제작 기준으로 삼되 정확한 UI·에셋·코드·Unity는 후속 승인 대상으로 둔다.
- [x] **Step 4:** 첫 튜토리얼은 `세균 감염 접속형`으로 확정한다. 세균막 각성→이동·물살→전이 감각 탐색→세균 표면 부착·유전물질 주입→의인화 미시 작동 화면→생물막 고정 습득·무손실 1회 실습→비그로테스크 픽셀 방출→새 숙주 능력 학습 규칙 예고로 진행한다. 캡시드는 세균 외부에 남고 동물 세포 직접 감염은 금지한다. 실패 시 안전 지점 재시작·무손실, 3회 실패 시 경로·목표를 상시 강조한다. `세균 숙주/운반 숙주`, `파지 고유 능력/세균 적응 특성/운반 숙주 경험 특성` 용어를 구분한다. 신규 콘텐츠는 안전 시점 강제 큐의 항목별 중앙 팝업으로 각각 `확인하고 연습`한 뒤 무손실 1회 실습하며, 재열람·저장·입력·접근성·다국어 계약을 따른다.
- [x] **Step 5:** 세균 감염 접속형과 신규 콘텐츠 팝업은 장기 시나리오·제작 후보이며 쥐 숙주 프로토타입에 자동 포함하지 않는다. 정확한 숏·에셋·UI·도감·저장 형식·코드·Unity는 후속 승인을 받는다.

- [x] **Step 5:** 사용자가 보호형 압축 편집 구조를 승인했다. 실제 스토리보드·이미지·에셋·애니매틱·오디오·Unity·코드 제작은 시작하지 않고 별도 승인으로 유지한다.
- [ ] **Step 6:** `총 비상호작용 러닝타임 = 오프닝 첫 프레임부터 T01 입력 해제까지 실제 연결 타임라인의 경과 시간 - 커스터마이징 상호작용 체류 시간`으로 산정한다. 중앙 문구 hold·전환·입력 잠금은 실제 타임라인 구성요소로 breakdown에 별도 표시하되 다시 더하지 않고, 건너뛰기 경로 시간은 정상 러닝타임과 별도 보고하며 입력 경계는 이벤트로 기록한다.

## Task 6: 스토리보드·이미지 후보

**Files:**

- Output after Gate A approval: 사용자 지정 후보 경로

**Interfaces:**

- Produces: 사용자 선택용 구도·레이어 후보와 생성 이력

- [ ] **Step 1:** 생성할 숏, 후보 수, 비율, 출력 경로와 금지 요소를 사용자에게 승인받는다.

## 단계별 중단 조건

다음 중 하나가 생기면 다음 제작 단계로 넘어가지 않는다.

- 청소 노동자가 발병 원인 또는 환자 0처럼 읽힘
- 파지가 인간 세포를 직접 감염한다고 표현됨
- 기원이 오프닝에서 전부 폭로되어 후반 미스터리가 사라짐
- 인간 전체나 연구자 전체가 단순 악역으로 묘사됨
- 무기 제작에 활용 가능한 구체적인 절차·물질·유전자·배양 조건이 포함됨
- 생성 후보가 기본 박테리오파지 실루엣을 잃음
- 문서 승인을 이미지·애니매틱·Unity 또는 전체 캠페인 구현 승인으로 확대함
- 쥐 숙주 프로토타입의 단독 시작 흐름을 승인 없이 변경함
