# 오프닝 시네마틱·주인공 기원

## 1. 문서 목적과 상태

이 문서는 `새 게임` 선택 후 시작되는 오프닝을 다음 흐름으로 연결하는 장기 시나리오 설계다.

> 평범한 일상과 감염병 확산 시네마틱 → 중앙 시작 텍스트 → 청소 노동자의 기침 → 비말과 배수 환경 → 주인공 각성 → 커스터마이징 → 첫 튜토리얼

오프닝은 `픽셀아트 모션 코믹형 시네마틱`으로 표현한다. 아래 내용은 사건·감정·전환의 기준이며 최종 숏이나 스토리보드 확정안은 아니다.

현재 메인 시나리오의 기존 `숲 바닥에서 시작하는 10~20초 도입`은 이번 사용자 승인 방향과 다르다. 상위 메인 시나리오를 실제로 교정하는 작업은 기존 미커밋 작업과의 충돌을 피하기 위해 별도 동기화 태스크로 둔다.

## 2. 한 문장 목적

평범한 일상이 무너지는 모습을 먼저 보여준 뒤, 누구도 주목하지 않은 노동자의 기침 속에서 작은 파지가 세상으로 나오게 하여, 플레이어가 재난의 원인이라고 오해할 수도 있는 존재와 직접 관계를 맺게 한다.

후반에는 주인공이 자연 발생 감염원이 아니라, 인간의 방어·치료 연구가 전쟁 속에서 무기화되는 과정에서 태어난 돌연변이였다는 사실을 점진적으로 드러낸다.

## 3. 핵심 서사 원칙

1. 감염병은 특정 개인의 행동이 아니라 평범한 이동과 접촉 속에서 이미 퍼지고 있다.
2. 청소 노동자의 기침은 감염의 시작이 아니라 거시 인간 세계와 미시 주인공 세계를 잇는 순간이다.
3. 청소 노동자는 보호와 정보가 부족한 환경에서 타인이 남긴 위험을 감당하는 피해자로 묘사한다.
4. 주인공 박테리오파지는 인간 세포를 직접 감염하지 않는다.
5. 기침 비말에는 세균, 파지와 환경 미생물이 함께 실려 이동한다.
6. 주인공은 비말과 오염수를 따라 배수 환경으로 이동한 뒤 세균 군집 가까이에서 깨어난다.
7. 주인공의 인공적 기원은 오프닝에서 폭로하지 않고 후반까지 점진적으로 공개한다.
8. 인간 전체를 악역으로 규정하지 않는다. 치료를 지키려던 사람, 군사화를 거부한 사람, 공포와 경쟁에 편승한 조직을 구분한다.

## 4. 생물학적 표현 경계

- 사람들의 증상과 감염병의 정확한 병원체는 오프닝에서 단정하지 않는다.
- 주인공 파지는 감염 세균이나 비말·오염수 속 세균과 함께 이동한다.
- 주인공이 사람의 세포 안에서 직접 증식하거나 기침을 조종한 것으로 표현하지 않는다.
- 감염병 위기와 군사화된 파지 연구는 연결되어 있지만, 주인공 하나가 모든 감염을 일으킨 것으로 단순화하지 않는다.
- 현실 연구를 참고하더라도 전이와 능력은 `현실 기반의 게임적 각색`임을 유지한다.

확산 구간에서는 주인공의 보라색, 파지 실루엣과 고유 음향 모티프를 사용하지 않는다. 이 시각·음향 언어는 시퀀스 D에서 비말 내부의 미시 세계로 들어간 뒤부터 사용해 불특정 감염병과 주인공 박테리오파지를 분리한다.

여기서 확정하는 것은 사건 순서와 감정 회수 구조다. 정확한 숏 수, 카메라 위치·이동, 레이어 구성, 초 단위 타이밍과 총 러닝타임은 후속 숏·스토리보드 승인 뒤 정한다.

### 시퀀스 C — 중앙 시작 텍스트

암전 뒤 화면 가운데에 짧은 텍스트만 표시한다. 이 문장은 플레이어에게 세계관의 표면적 관점을 제시하고, 후반 연구소에서 의미가 뒤집힌다.

가확정 시작 문구:

> 우리는 너무 많은 것을 잃었다.
>
> 살아남기 위해, 우리는 적을 알아야 했다.

가확정 반전 문구:

> 우리는 적을 이해한 것이 아니었다.
>
> 우리는 새로운 적을 만들어냈다.

마지막 선택을 향한 질문 후보:

> 만들어진 존재는, 만들어진 목적대로 살아야 하는가?

두 문구는 현재 제작 진행 기준으로 가확정한다. 실제 연출·편집 과정에서 화면 흐름·톤·가독성과 맞지 않는 문제가 확인되면 임의 변경하지 않고 사용자 재검토 후 수정할 수 있다. 화자, 음성 사용 여부와 언어별 줄바꿈은 후속 승인 대상이다.

### 중앙 문구 한국어 가독성 기준

- 가확정 시작 문구와 반전 문구는 각각 하나의 문구 블록으로 보고, 한국어 제작 기준을 블록당 최대 2줄·완전히 읽을 수 있는 상태 최소 5초로 가확정한다.
- 페이드 인·아웃 시간은 최소 5초의 읽기 시간에 포함하지 않는다. 페이드와 겹쳐 표시해야 한다면 전체 노출 시간을 늘려 완전한 명도와 대비로 읽을 수 있는 시간이 5초 이상이 되게 한다.
- 폰트 크기, 실제 해상도와 접근성 테스트에서 읽기 시간이 부족하면 표시 시간을 늘릴 수 있다. 5초 미만으로 줄여야 한다면 임의 축소하지 않고 사용자 재검토를 거친다.
- 다른 언어에는 2줄을 강제하지 않는다. 번역문의 의미 보존, 언어별 읽기 속도와 폰트 fallback의 실제 가독성을 기준으로 줄 수와 표시 시간을 다시 조정한다.

### 최소 내레이션 운용 원칙

- 기본 정보는 환경음, 인물의 행동과 화면 문구로 전달한다.
- 내레이션은 시각 정보만으로 의미가 불명확하거나 핵심 전환의 이해를 보조해야 할 때만 제한적으로 사용한다.
- 가확정 시작 문구와 반전 문구를 모두 음성으로 중복 낭독하지 않는다. 어느 문구를 음성화할지 또는 둘 다 화면 문구로만 둘지는 후속 연출 판단 대상으로 남긴다.
- `OPEN-B07`의 기침 직후에는 짧은 무음을 확보하고, 그 위에 내레이션을 겹치지 않는다. 이후 미시 세계의 환경음과 주인공 음향 모티프가 시작되도록 거시 세계에서 미시 세계로 들어가는 리듬을 보호한다.
- 정확한 화자, 최종 대사량과 언어별 녹음 방식은 숏·읽기 시간과 함께 후속 결정한다.

### 시퀀스 D — 기침과 미시 세계

배경은 `영업 종료 직전부터 심야까지의 복합 환승시설 청소 구역`이다. 동선은 승객이 빠져나가는 환승 통로에서 승강장 인접 공용구역을 지나 직원용 세척·배수 구역으로 이어진다. 이 연결은 앞선 시퀀스 B의 복합 환승 노드가 밤에도 유지·정리되는 같은 생활 환경임을 보여주되, 정확한 숏 수·카메라·러닝타임은 확정하지 않는다.

노동자는 피곤한 몸으로도 통행을 방해하지 않게 도구를 정리하고 젖은 바닥을 확인하며 맡은 일을 마치는 성실하고 평범한 생활인이다. 이름·가족관계·국적 같은 인적 정보는 장면 이해에 필요한 최소치만 사용하고, 빈곤·비위생 캐리커처나 확정 사망·중증화로 감정을 강요하지 않는다.

Task 3 Step 2의 제작 기준 가안은 `마감 동선 추적형 + 성실한 행동 한 비트`다. 종료 안내와 승객 감소 → 젖은 바닥 안내물 배치로 통행 확보 → 정상 장갑·작업복 차림으로 환승 통로 청소 → 카트를 승강장 인접 구역에서 직원 세척 구역으로 이동 → 밀대·도구 헹굼과 정돈 → 사람과 작업물에서 고개를 돌려 짧은 기침 → 순간 무음과 비말 확대 → 비말 속 세균 군집·환경 미생물·여러 파지 중 주인공 식별 → 세척수의 얕은 물막 합류 → 격자 배수구와 세균막 미세환경 진입 순서로 연결한다.

핵심 소품은 카트·밀대, 정상 장갑·작업복, 젖은 바닥 안내물, 환기구, 세척통·세척대, 물막·격자 배수구로 제한한다. 파손 보호구, 방치 오물, 경고 무시·미완료 체크, 기침 뒤 새 감염 피해, 인간 세포 감염 묘사는 사용하지 않는다. 주인공 고유 색·음향은 비말 내부에 진입한 뒤부터 시작한다. 이 기준은 보호 결핍이나 특정 기관의 과실을 선확정하지 않는 제작 가안이며, 스토리보드와 결과물 검토 뒤 사용자 승인으로 수정할 수 있다.

## 6. 길이 산정 원칙

오프닝 총길이는 먼저 정하지 않는다. 다음 순서로 내용을 확정한 뒤 결과값으로 산정한다.

1. 반드시 전달할 사건 비트를 고정한다.
2. 독립 씬과 연결 시퀀스의 수를 정한다.
3. 각 씬을 실제 숏으로 나누고 숏별 정보량과 감정 호흡을 정한다.
4. 자막 읽기, 제한 모션, 전환과 무음의 최소 시간을 배정한다.
5. 모든 숏의 길이를 합산해 첫 조작 도달 시간과 제작비를 검토한다.
6. 지나치게 길거나 핵심 정보가 읽히지 않을 때만 숏을 합치거나 내용을 줄인다.

현재 회사원·학생·가족의 독립 3씬과 별도 혼합형 감염 확산 구간은 확정됐지만, 숏 수와 내용이 남아 있으므로 총길이는 미정이다.

한 번 본 오프닝의 건너뛰기·재시청 여부는 Unity 구현 단계에서 별도 확정한다.

## 7. 청소 노동자 묘사 안전장치

### 반드시 보여줄 것

- 노동자가 등장하기 전에 여러 장소와 사람에게 이미 증상과 확산 흔적이 존재한다.
- 노동자는 타인이 남긴 위험을 치우기 위해 투입된다.
- 보호구, 환기, 습식 바닥과 배수구 같은 구조적 환경 노출을 배경에 두되 특정 기관이나 안전수칙 위반을 단일 원인으로 지목하지 않는다.
- 노동자의 얼굴과 기침은 조롱이나 혐오가 아니라 피로와 취약성으로 표현한다.
- 후반 기록에서도 노동자를 `최초 감염자`, `유출 책임자`, `원인 제공자`로 부르지 않는다.
- 노동자의 인적 정보는 필요 최소치로 유지하고 확정 사망이나 중증화를 부여하지 않는다.

### 금지할 것

- 노동자의 위생 습관이나 부주의가 재난을 만들었다는 구도
- 기침 순간에 악의적 음악이나 괴물화 효과 사용
- 특정 계층·국적·직업을 감염원으로 연상시키는 상징
- 노동자의 신원을 비난이나 추적 대상으로 사용하는 전개

## 8. 주인공 커스터마이징

커스터마이징은 `레이어형 혼합`으로 외형과 애착을 형성하는 단계다. 초기 외형과 성격 강조점은 능력치·변이 확률·엔딩 성향에 영향을 주지 않는다.

### 초기 제공 항목

- 보라·분홍·흰색 중심 제한 팔레트 안의 색 조합 6종
- 눈·눈썹·입을 묶은 친근한 얼굴·표정 세트 4종
- 기본 실루엣을 가리지 않는 캡시드 무늬 4종
- 짧고 둥근 spike의 작은 형태 차이 2종
- 자유 이름 입력과 추천 이름 목록
- `호기심`, `용감`, `장난기` 중 성격 강조점 선택. 이는 대기 표정·짧은 반응·문구의 어조를 보조할 뿐 게임 수치와 분기를 바꾸지 않는다.

### 진행 중 해금

- 추가 제한 팔레트, 얼굴·표정 세트와 캡시드 무늬
- 방향별 가독성과 실루엣 보존을 검증한 짧고 둥근 spike 장식
- 기본 실루엣을 가리지 않는 작은 배지와 은은한 발광 흔적

해금 외형도 능력치·변이 확률·엔딩 성향과 분리한다. 부분 방어구, 결정 성장, 발광 바이러스 코어와 진화한 spike는 능력·성장을 읽히게 하는 시각 언어로 예약하며 일반 커스터마이징에 섞지 않는다.

### 고정 실루엣과 금지 변경

- 전체 높이의 60~70%인 큰 정이십면체 캡시드
- 매우 짧은 2~3분절 몸
- 팔 2개, 다리 2개와 작은 파지 꼬리
- 짧고 둥근 spike

팔다리 수·길이, 꼬리 유무, 과도하게 길거나 날카로운 spike는 변경하지 않는다. 모든 선택·해금·성장 레이어는 얼굴, 팔다리, 캡시드 윤곽과 종 식별성을 보존한다.

### 시간·재생 연속성

- 커스터마이징 전 모든 주인공 장면은 기본 보라 팔레트·기본 표정·기본 무늬·기본 spike의 확정 기본형을 선명하게 보여준다.
- 커스터마이징 확정은 기본형이 선택 외형으로 실제 변화하는 장면이다.
- 확정 뒤의 컷신·픽셀아트 모션 코믹·인게임·메뉴·초상은 해당 저장 슬롯의 현재 선택 외형을 사용한다.
- 오프닝 재시청에서 커스터마이징 전 구간은 항상 기본형, 이후 구간은 저장 슬롯의 현재 선택 외형을 사용한다.
- 회상은 서사 시점이 커스터마이징 전이면 기본형, 이후면 저장 슬롯의 현재 선택 외형을 사용한다.
- 성장·변이는 선택 외형 위에 장면의 서사 시점에 맞는 별도 레이어로 적용한다.

### 제작 경계

색은 팔레트, 얼굴·무늬·spike는 방향·상태별 레이어로 합성한다. spike는 외곽선과 방향별 프레임 비용을 늘리므로 2종으로 제한하고, 픽셀아트 모션 코믹은 승인된 주인공 포즈를 재사용해 조합 폭발을 막는다. 정확한 UI, 저장 형식, 방향별 스프라이트·초상·모션 코믹 에셋, 코드와 Unity 적용은 후속 승인 대상이다.

## 9. 첫 튜토리얼 — 세균 감염 접속형

첫 튜토리얼은 박테리오파지의 실제 감염 대상이 세균임을 조작으로 가르치는 `세균 감염 접속형`이다.

1. 세균막에서 각성한 주인공이 기본 이동으로 물살을 따라가고 방향을 보정한다.
2. 파지 고유 능력 `전이 감각`을 사용해 감염에 적합한 세균 숙주와 안전 경로를 찾는다.
3. 세균 표면에 부착해 유전물질을 주입한다. 캡시드는 세균 외부에 남으며, 인간·곤충·쥐를 포함한 동물 세포를 직접 감염하는 표현은 사용하지 않는다.
4. 감염·적응 과정을 의인화한 미시 작동 화면으로 전환한다. 이 화면은 캡시드 전체가 세균 안에 들어가는 해부학적 묘사가 아니다.
5. 세균 적응 특성 `생물막 고정`을 습득하고 한 번 사용해 물살에 밀리지 않는 무손실 실습을 완료한다.
6. 감염 과정의 완료와 방출은 그로테스크한 파괴 대신 픽셀 분해·발광 전환으로 표현한다.
7. 새 세균 숙주에서는 새 세균 적응 특성, 운반 숙주에서는 새 운반 숙주 경험 특성을 배울 수 있다는 규칙을 짧게 예고한다.

기본 조작은 이동, 세균 부착·주입 상호작용과 `전이 감각` 한 가지 능동 스킬에 집중한다. 파지 고유 능력은 기본 이동·표적 부착/주입·환경 안정성을 포함하며, 초기 능동 스킬은 `전이 감각`, 첫 세균 숙주 능력은 `생물막 고정`이다.

실패하면 직전 안전 지점에서 즉시 다시 시작하고 자원·생명을 잃지 않는다. 같은 단계에서 3회 실패하면 안전 경로와 목표 세균을 상시 강조한다. 한 번에 새 조작 하나만 제시하고, 설명을 읽은 뒤 바로 한 번 사용하게 해 정보 과잉을 막는다.

### 용어 구조

- `세균 숙주`: 파지가 실제로 부착·감염·증식하는 생물학적 숙주
- `운반 숙주`: 곤충·쥐처럼 파지와 감염 세균을 미생물군·표면·체액 환경을 통해 운반하는 거시 생물
- `파지 고유 능력`: 처음부터 주인공이 가진 능력
- `세균 적응 특성`: 세균 숙주에서 학습한 능력
- `운반 숙주 경험 특성`: 운반 숙주의 이동·생존 방식에서 학습한 장기 특성

거시 생물 조종은 미생물 환경과 게임적 간접 영향으로 설명하며, 파지가 인간·곤충·쥐 세포를 직접 감염한다고 표현하지 않는다.

### 신규 콘텐츠 중앙 알림 계약

신규 내용은 발생 즉시 알림 큐에 등록하고, 연출·전환·위험 판정이 끝난 첫 안전 시점에 항목별 중앙 팝업으로 표시한다. 팝업이 열린 동안 게임 시간과 위험 판정을 정지하며, 사용자가 `확인하고 연습`을 클릭하거나 대응 입력을 하기 전에는 자동 소멸, 바깥 클릭, 취소 입력이나 장면 전환으로 닫히지 않는다. 여러 항목은 한 창에서 `1/N` 순서로 각각 확인한다.

필수 알림 대상은 신규 능동·수동 스킬, 세균 적응 특성, 운반 숙주 경험 특성, 새 시스템·모드·자원·게이지·위험·상태·조작·숙주 규칙·성장/변이 방식과 플레이 판단을 바꾸는 핵심 정보다. 이미 확인한 동일 유형의 반복 개체, 수치만 다른 변형과 배경 장식은 제외하고, 기존 항목의 의미가 바뀔 때만 콘텐츠 버전을 올려 다시 알린다.

각 팝업은 신규 상태, 이름, 종류, 효과 한 문장, 조작·발동 조건, 짧은 사용 예와 실습 예고를 표시한다. 확인 뒤 능동 조작은 실제 사용, 수동 효과는 보호된 예시 관찰, 자원·위험은 무손실 예시 수행처럼 해당 내용을 한 번 증명하는 실습을 완료한다.

도감·스킬 메뉴에는 `파지 고유 능력`, `세균 적응 특성`, `운반 숙주 경험 특성`, `시스템·조작`, `자원·위험`, `숙주·생태 정보`, `최근 발견` 분류를 두고 팝업 원문과 다시 연습 기능을 제공한다.

알림 상태는 저장 슬롯별 `Queued` → `PresentedUnconfirmed` → `ConfirmedNeedsPractice` → `Completed`로 관리하고 각 전환을 즉시 저장한다. 종료·재시작 시 미확인 팝업 또는 미완료 실습부터 재개하며, 콘텐츠 ID로 중복을 막고 의미 변경 시에만 버전을 올린다.

키보드·마우스와 패드의 현재 입력 glyph, 키 재설정, 포커스 연속 입력 방지, 시간 제한 없음, 글자 크기·고대비·색 외 종류 아이콘·스크린리더 순서와 다국어 의미 중심 가변 레이아웃을 지원한다.

이 첫 튜토리얼과 알림 계약은 장기 시나리오·제작 후보이며 현재 승인된 쥐 숙주 프로토타입 구현 범위에 자동 포함되지 않는다. 정확한 숏·에셋·팝업 UI·도감·저장 형식·코드와 Unity 적용은 후속 승인 대상이다.

## 10. 주인공 기원의 내부 확정 사실

플레이어에게는 점진적으로 공개하지만 제작 내부에서는 다음을 사실로 유지한다.

1. 연구는 감염성 세균과 항생제 내성 위협에 대응하기 위한 방어·치료 목적에서 시작됐다.
2. 전쟁이 장기화되면서 지휘·예산 체계가 연구를 군사적 통제와 무기 연구로 전환했다.
3. 주인공은 그 군사화 과정에서 예상하지 못한 방향으로 살아남고 변이한 박테리오파지다.
4. 폐기·격리·운반 체계의 실패를 통해 감염 세균 또는 환경 미생물과 함께 외부로 이동했다.
5. 청소 노동자는 이 과정에 관여하거나 이를 알지 못했으며, 오염된 생활 환경에 노출된 피해자다.
6. 연구진 전체가 군사화를 지지한 것은 아니다. 치료 목적을 지키거나 기록을 남기거나 중단시키려 한 사람도 있었다.
7. 군사화된 연구와 현재 감염병 위기의 관계는 존재하지만, 주인공 하나가 모든 감염을 일으킨 것으로 단순화하지 않는다.

생화학 무기의 물질, 유전자, 제조, 배양, 전달 또는 최적화 절차는 설정 문서에도 기록하지 않는다.

## 11. 기원 미스터리 공개 단계

| 단계 | 플레이어가 아는 것 | 공개 수단 | 아직 감출 것 |
| --- | --- | --- | --- |
| 오프닝 | 주인공이 비말·배수 환경에서 깨어났고 일반적인 파지와 다른 흔적이 있음 | 캡시드의 희미한 표식, 불완전한 음향 또는 짧은 이미지 잔상 | 연구소, 전쟁, 군사화와 제작 주체 |
| 초반 | 일부 변이가 우연이라고 보기 어려울 정도로 규칙적임 | 변이 카드의 분류 코드 조각, 특정 환경에서 반응하는 표식 | 치료 연구의 정체와 생성 과정 |
| 중반 | 주인공과 유사한 신호를 추적한 기록이 존재함 | 버려진 운송 라벨, 방역 데이터, 서로 충돌하는 기록 | 연구가 치료에서 무기로 바뀐 이유 |
| 병원 구간 후보 | 초기 목적이 감염 방어와 치료였음 | 의료 기록의 일부, 연구자의 음성·문서 조각 | 군사화 명령과 주인공의 직접 연결 |
| 연구소 구간 후보 | 전쟁 중 연구가 무기 연구로 전환됐고 주인공이 그 과정에서 태어남 | 보존 기록, 폐쇄 명령, 반대 연구자의 마지막 기록 | 최종 책임을 한 개인에게 단순 귀속하지 않음 |
| 마지막 선택 | 주인공이 만들어진 목적과 다른 생존 방식을 선택할 수 있음 | 플레이어 행동과 엔딩 분기 | 정답 엔딩을 강요하지 않음 |

병원·연구소 구간은 장기 제안이며 현재 구현 승인이 아니다.

## 12. 돌연변이 능력 층

### 현실 기반 층

- 특정 세균을 감염하고 세균 군집 안에서 증식
- 환경과 표적 세균 변화에 대한 적응
- 감염 세균, 생물막, 물과 오염 표면을 통한 이동
- 표적 범위, 안정성, 잠복과 증식 방식의 변화
- 세균과 파지 사이의 방어·대응 경쟁

### 게임적 확대 층

- 세균 군집과 환경 경로를 감지하는 `전이 감각`
- 숙주의 미생물군 상태를 이용한 면역 압박 완화
- 세균이 만드는 화학 신호를 통한 거시 숙주의 행동 경향 간접 영향
- 환경 위험에 대한 제한적 내성
- 이전 숙주 경험을 이용한 새 이동 경로 또는 전이 접점 발견

이 층은 거시 숙주를 직접 정신 지배하는 현실 주장으로 설명하지 않는다.

### 초고도 변이 층

- 여러 세균 군집 사이의 분산된 감각망
- 거시 숙주의 본능과 행동에 대한 강한 간접 조정
- 새로운 세균 환경을 빠르게 해석하는 적응 코어
- 의료 대응 정보를 게임적으로 분석하는 진화 기능
- 여러 숙주와 환경에 흔적을 남기는 네트워크형 존재

초고도 변이는 강할수록 숙주 부담, 인간 위험도, 정체성 변화 또는 엔딩 경향 같은 비용을 가져야 한다. 기본 박테리오파지 실루엣은 모든 층에서 유지한다.

## 13. 확정·미정·승인 경계

### 이번 논의로 확정한 방향

- 일상·확산 시네마틱 뒤 중앙 텍스트를 거쳐 청소 노동자의 기침과 주인공 각성으로 이어지는 순서
- 노동자는 원인이나 환자 0이 아닌 구조적 피해자
- 파지는 인간 세포가 아니라 감염 세균·비말·오염 환경을 통해 이동
- 방어·치료 연구가 전쟁 중 군사화됐고 주인공은 그 과정에서 태어난 돌연변이체
- 기원은 오프닝에서 전부 폭로하지 않고 후반까지 점진 공개
- 능력을 현실 기반·게임적 확대·초고도 변이로 구분
- 커스터마이징은 기본 실루엣과 초기 능력에 영향을 주지 않음
- 현재 시작·반전 문구는 제작 진행 기준으로 가확정하며, 실제 연출·편집에서 화면 흐름·톤·가독성 문제가 확인될 때만 사용자 재검토 후 수정
- 내레이션은 환경음·행동·화면 문구를 우선하는 최소 내레이션으로 운용하고, 기침 직후 무음과 미시 세계 진입 리듬을 침범하지 않음
- 한국어 시작·반전 중앙 문구는 블록당 최대 2줄·완전 가독 시간 최소 5초로 가확정하고, 다른 언어는 의미·읽기 속도·폰트 fallback에 따라 재조정
- 청소 노동자의 작업 공간은 영업 종료 직전~심야의 복합 환승시설 청소 구역이며, 환승 통로→승강장 인접 공용구역→직원용 세척·배수 구역의 연결 동선을 사용

### 사용자 결정이 필요한 항목

- 숏별 정보량을 반영한 오프닝 총길이와, 필요 시 가확정 문구의 재검토
- 최소 내레이션의 정확한 화자, 최종 대사량과 언어별 녹음 방식
- 정식 첫 숙주와 첫 지도
- 숏별 구도·레이어·길이와 스토리보드 후보
- 정확한 숏 수·러닝타임·에셋과 Unity 적용

### 승인 전 금지 해석

- 이 문서를 전체 캠페인, 벌레 튜토리얼 또는 새 미세 이동 모드의 구현 승인으로 보지 않는다.
- 쥐 숙주 프로토타입 시작 흐름을 자동 교체하지 않는다.
- 이미지·영상·애니매틱·오디오·Unity 제작을 시작하지 않는다.
