# 오프닝·기원 설계

이 폴더는 `마지막 숙주 / The Last Host`의 게임 시작 시네마틱, 주인공 박테리오파지의 기원 미스터리, 커스터마이징과 첫 튜토리얼 전환을 정리한다.

## 포함 문서

- [오프닝 시네마틱·주인공 기원](opening-cinematic-origin.md)
  - 평범한 일상과 감염병 확산부터 청소 노동자의 기침, 주인공 각성, 커스터마이징과 튜토리얼까지 이어지는 서사 설계
  - 방어·치료 연구가 전쟁 중 무기 연구로 변질된 기원과 점진적인 공개 구조
  - 현실 기반·게임적 확대·초고도 변이 능력의 구분
- [오프닝 시네마틱 제작 계획](opening-cinematic-production-plan.md)
  - 현재 가능한 문서 작업과 별도 승인이 필요한 스토리보드·이미지·애니매틱·오디오·Unity 작업의 단계별 분리
  - 역할별 인계, 승인 게이트와 검증 조건
- [오프닝 편집 비트 후보·기원 공개 장부](opening-shot-spec.md)
  - `33개 편집 비트 후보`의 시작·종료 상태, 단일 서사 목적, 공개·비공개 정보와 병합 경계
  - 최종 숏 수와 시간을 선확정하지 않는 실제 측정 산식, 커스터마이징·첫 조작 입력 경계

## 상태와 효력

- 픽셀아트 모션 코믹형 시네마틱은 프로젝트의 기본 컷신 형식이다.
- 이 폴더의 오프닝과 기원은 전체 캠페인을 검토하기 위한 장기 시나리오 설계다.
- 편집 비트 후보와 기원 공개 장부는 승인됐지만, 개별 숏의 최종 수·구도·레이어·시간·대사, 생성 이미지, 애니매틱, 오디오와 Unity 구현은 아직 승인되지 않았다.
- 현재 구현 승인 범위는 작은 하수도 맵의 쥐 숙주 프로토타입으로 유지한다.

## 필수 경계

- 주인공은 박테리오파지이며 인간 세포를 직접 감염하지 않는다.
- 사람과 동물은 감염 세균, 비말, 오염수와 파지를 운반하는 거시 숙주 또는 운반체로 표현한다.
- 청소 노동자는 감염의 원인이나 환자 0이 아니라 이미 확산된 재난에 노출된 구조적 피해자다.
- 생화학 무기의 물질, 유전자, 배양 조건이나 제작 절차는 다루지 않는다.
