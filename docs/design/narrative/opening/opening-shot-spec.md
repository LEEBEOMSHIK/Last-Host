# 오프닝 편집 비트 후보·기원 공개 장부

## 1. 문서 목적과 효력

이 문서는 승인된 오프닝 사건을 스토리보드와 비최종 애니매틱에서 비교할 수 있도록 `33개 편집 비트 후보`로 분해한다. `A01~A06`, `B01~B10`, `C01`, `D01~D12`, `E01~E03`, `T01`은 추적용 후보 ID이며 최종 숏 수, 최종 패널 수나 편집 길이가 아니다.

- 인접 비트는 아래 병합 조건을 만족할 때 한 숏 또는 한 패널 안에서 결합할 수 있다.
- 한 비트가 여러 패널로 나뉘어도 원래 ID와 서사 목적을 추적한다.
- 서로 다른 사실, 감정 또는 입력 경계를 가진 비트는 제작비 절감을 이유로 병합하지 않는다.
- 이 문서는 후보 구도·움직임·전환을 제안하지만 최종 스토리보드, 카메라, 레이어와 타이밍 명세는 아니다.
- 이미지·에셋·애니매틱·오디오·Unity 제작은 승인하지 않는다.
- 쥐 숙주 프로토타입의 시작 흐름을 변경하지 않는다.

## 2. 시간과 입력 산정 계약

- 초 단위 숏 길이, 총 러닝타임, 목표·최소·최대 러닝타임과 `짧음·중간·김` 등급은 지금 확정하지 않는다.
- 유일하게 유지하는 시간 계약은 `C01` 중앙 문구가 한국어 기준 최대 2줄이며 **완전한 명도와 대비로 최소 5초** 읽혀야 한다는 점이다. 페이드 인·아웃은 이 5초에 포함하지 않는다.
- `D07` 기침 직후 무음은 반드시 존재하지만 정확한 길이는 승인된 스토리보드와 비최종 애니매틱에서 호흡을 실제 측정한 뒤 정한다.
- 총 비상호작용 러닝타임은 다음 산식으로 실제 연결 뒤 산정한다.

> 총 비상호작용 러닝타임 = 오프닝 첫 프레임부터 `T01` 입력 해제까지 실제 연결 타임라인의 경과 시간 - 커스터마이징 상호작용 체류 시간

- 중앙 문구 hold, 전환과 입력 잠금은 실제 연결 타임라인에 포함되는 구성요소다. breakdown에는 각각의 실제 측정값을 별도 표시하되 총 비상호작용 러닝타임에 다시 더하지 않는다.
- 커스터마이징에서 사용자가 머무는 상호작용 체류 시간은 위 산식으로 제외하고 별도 보고한다.
- 건너뛰기 경로의 경과 시간은 정상 러닝타임과 별도로 보고한다. 건너뛰기 시간을 정상 경로에서 더하거나 빼지 않는다.
- `E01`에서 첫 사용자 입력이 시작되고, `E02` 변환 중 다시 잠근 뒤 `E03` 또는 병합된 `E03+T01`의 명시적 경계에서 실제 이동 입력을 해제한다. 각 잠금·해제 지점은 시간 가산값이 아니라 타임라인 이벤트로 기록한다.

## 3. 승인 게이트 약어

| 약어 | 후속 승인 |
| --- | --- |
| `S` | 최종 스토리보드·패널·구도·레이어 명세 |
| `A` | 이미지 후보 또는 실제 픽셀 에셋 제작 |
| `M` | 비최종 애니매틱과 실제 측정 타이밍 |
| `AU` | 오디오·성우·믹싱 |
| `U` | Unity 재생·입력·저장·건너뛰기 구현 |

## 5. 병합 규칙 요약

병합 후보는 최종 숏 수를 줄이라는 지시가 아니라 스토리보드에서 비교할 편집 선택지다.

| 병합 후보 | 허용 조건 | 유지해야 할 경계 |
| --- | --- | --- |
| `A01+A02`, `A03+A04`, `A05+A06` | 같은 독립 생활 씬 안에서 행동의 시작과 평온한 종료가 모두 읽힘 | 회사·학교·가정 세 씬은 서로 독립 유지 |
| `B08+B09` | 업무·교육의 두 공백이 각각 식별되는 병렬 패널 | `B10` 관계의 공백은 별도 호흡 유지 |
| `D01+D02` | 종료 안내·승객 감소 뒤 안내물 배치의 선후가 분명함 | 노동자가 먼저 안전 동선을 확보한다는 사실 |
| `D03+D04` | 통로 청소 완료 뒤 카트 이동으로 자연스럽게 연결됨 | 정상 장비·평범한 노동과 공간 연결을 모두 보존 |
| `D09+D10+D11` | 물막 합류→격자 통과→세균막 도달의 방향이 끊기지 않음 | 인체 내부가 아닌 환경 운반 경로와 세균막 도착 |
| `E03+T01` | 같은 플레이 구도 안에서 입력 잠금 해제 마커가 명시됨 | 시네마틱 종료 상태와 첫 실제 입력 성공 상태를 각각 기록 |

다음 의미 경계는 병합하지 않는다.

- `B03` 다중 접촉 가능성과 `B04~B06` 대표 생활권 경로
- `B10` 관계의 공백과 `C01` 세계관 문구
- `D05` 성실한 작업 완료와 `D06` 기침
- `D06` 기침과 `D07` 무음·비말 포착
- `D07` 거시·미시 경계와 `D08` 주인공·세균 군집 식별
- `D11` 세균막 도착과 `D12` 주인공 각성
- `E01` 사용자 입력 시작, `E02` 확정 후 입력 잠금, `T01` 실제 이동 입력 해제

## 7. 스토리보드·애니매틱 인계 조건

Task 5로 넘어가기 전 다음을 사용자에게 다시 승인받는다.

- 유지·병합·분할할 편집 비트와 결과 패널 수
- 숏별 최종 구도, 레이어, 카메라, 패럴랙스와 전환
- 중앙 문구 외 모든 실제 측정 타이밍과 기침 뒤 무음 호흡
- 최소 내레이션의 화자·대사량·언어별 녹음 방식
- 이미지 후보 생성 여부·수량·출력 경로
- 비최종 애니매틱, 오디오와 Unity 재생의 개별 제작 승인

이 승인을 받기 전에는 본 문서의 후보를 최종 스토리보드, 최종 러닝타임, 이미지·에셋·애니매틱·오디오 또는 Unity 구현 명세로 승격하지 않는다.
