# 숙주·서식지 맵·전이 루트 설계 초안

## 문서 성격

이 문서는 정식 캠페인의 숙주 범위와 월드 이동 구조를 정리하는 장기 기획 초안이다. 원본 `.docx`와 현재 Markdown 기획을 바탕으로 하되, 2026-08-08 사용자 논의에서 승인된 다음 방향을 반영한다.

- 전체 진행은 엄격한 단일 먹이사슬이 아니라 `먹이 관계 + 감염·접촉·환경 이동`을 함께 쓰는 혼합형이다.
- 각 동물은 자신의 생활권에 해당하는 맵과 연결된다.
- 한 지역군 안에서는 여러 맵을 왕복할 수 있다.
- 다음 지역군을 연 뒤에도 이전 맵으로 돌아갈 수 있지만, 현재 숙주가 이용할 수 있는 경로만 통과할 수 있다.

이 문서는 전체 캠페인 구현 승인 문서가 아니다. 현재 구현 승인 범위는 작은 하수도 맵의 쥐 숙주 프로토타입으로 유지한다.

## 핵심 세계관 경계

기본 캐릭터는 박테리오파지이므로 동물 세포를 직접 감염하는 바이러스로 다루지 않는다. 게임에서 동물은 플레이 규모상 `숙주`라고 부르지만, 생물학적으로는 바이러스와 감염 세균을 품고 이동시키는 **거시 숙주 또는 운반체**에 가깝다. 박테리오파지의 실제 증식 대상은 동물 안팎의 세균이다.

따라서 숙주 전이는 다음 중 하나로 설명한다.

- 감염 세균이 먹이와 함께 이동한다.
- 침, 배설물, 상처, 오염된 물·먹이·표면을 통해 세균과 파지가 이동한다.
- 포식자가 이전 숙주를 먹으면서 장내 미생물 환경으로 진입한다.
- 인간이나 동물의 접촉, 사육, 구조, 진료, 운반 과정에서 새로운 생활권으로 이동한다.

이 해석은 파지가 세균을 감염하며 동물 장내 미생물군 안에서 확산될 수 있다는 연구를 참고한 게임적 각색이다. 실제 종간 이동 가능성과 결과는 파지와 표적 세균에 따라 달라지므로, 특정 동물 간 전이를 현실의 확정 사실로 표현하지 않는다.

참고:

- [Phollow: 살아 있는 동물과 미생물군에서의 파지 전파 관찰](https://pmc.ncbi.nlm.nih.gov/articles/PMC11195241/)
- [야생 생쥐 파지군의 사육 생쥐 장내 정착 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC11440513/)

## 월드 구조: 지역군과 맵 노드

월드는 하나의 긴 스테이지 목록이 아니라 여러 `지역군`이 연결된 맵 그래프로 구성한다. 지역군은 같은 생태·생활권에 속하는 2~3개의 플레이 맵을 묶는다.

```text
자연 미소환경
      ↓
농경지·축사권
  ├──────────────┐
  ↓              ↓
도시 지하권 ↔ 도시 생활권
                  ↓
              인간 통제권
```

각 맵 노드는 다음 정보를 가진다.

| 항목 | 의미 |
| --- | --- |
| 생활권 | 숲 바닥, 축사, 하수도, 주택가처럼 맵의 생태적 성격 |
| 출현 숙주 | 해당 공간에서 자연스럽게 만날 수 있는 동물 |
| 이동 경로 | 현재 숙주가 직접 사용할 수 있는 통로 |
| 전이 접점 | 포식, 접촉, 먹이, 물, 배설물 등 숙주를 바꿀 기회 |
| 위험 | 포식자, 면역 압박, 인간 방역, 차량, 격리 등 |
| 회귀 열쇠 | 이전 맵으로 돌아가기 위해 필요한 숙주나 경험 특성 |

## 권장 지역군 초안

| 지역군 | 대표 맵 | 주요 숙주 후보 | 다음 지역으로 이어지는 접점 |
| --- | --- | --- | --- |
| 1. 자연 미소환경 | 숲 바닥, 썩은 통나무, 연못·풀숲 가장자리 | 곤충, 모기 | 포식, 고인 물, 먹이 섭취 |
| 2. 농경지·축사권 | 밭둑, 사료 창고, 닭장·축사 | 쥐, 닭, 가축, 포식성 조류 | 먹이사슬, 사료·물 오염, 사육자 접촉 |
| 3. 도시 지하권 | 배수관, 하수도 본관, 지하 창고 | 쥐, 해충 | 배관, 쓰레기, 지상 출구 |
| 4. 도시 생활권 | 골목, 주택가, 공원·옥상, 동물 진료·구조 접점 | 쥐, 고양이, 개, 조류, 인간 | 반려동물 접촉, 구조·진료, 음식·표면 오염 |
| 5. 인간 통제권 | 병원, 격리 구역, 연구소 | 인간, 배양 세균, 현재 거시 숙주 | 검사, 치료, 연구, 최종 선택 |

지역군 이름과 맵 수는 제작 범위 확정 때 조정할 수 있다. 이 단계에서는 각 숙주가 자신의 생활권과 연결되고, 생활권 사이에 납득 가능한 전이 접점이 존재한다는 구조만 고정한다.

## 숙주 범위 초안

기존의 단일 `새` 항목은 먹이사슬 위치가 서로 다르므로 두 역할로 나눈다.

| 숙주군 | 먹이망·전이 역할 | 대표 생활권 | 캠페인 위치 |
| --- | --- | --- | --- |
| 곤충 | 가장 작은 시작 운반체, 먹이가 되어 상위 숙주로 이동 | 숲 바닥, 통나무, 풀숲 | 초반 필수 후보 |
| 모기 | 물과 육상 생활권을 잇는 선택형 연결자 | 고인 물, 연못가, 축사 주변 | 초반 선택 후보 |
| 쥐 | 곤충을 먹고 오염 환경과 인간 생활권을 잇는 핵심 숙주 | 밭둑, 사료 창고, 하수도, 골목 | 핵심 필수 후보 |
| 닭·소형 잡식성 조류 | 곤충과 농장 먹이망을 잇는 중간 숙주 | 밭, 닭장, 축사 주변 | 농장 분기 후보 |
| 포식성 조류 | 쥐보다 상위 먹이사슬을 명확히 보여주는 포식자 | 농경지 상공, 숲 가장자리, 공원·옥상 | 상위 포식 루트 후보 |
| 고양이 | 쥐 포식과 반려동물 접촉을 통해 인간 생활권으로 연결 | 골목, 주택, 동물병원 | 도시 분기 후보 |
| 개 | 사냥·접촉·반려 생활을 통해 도시와 인간을 연결 | 주택가, 공원, 동물병원 | 도시 분기 후보 |
| 가축 | 사료·물·사육자 접촉을 통해 농장과 인간을 연결 | 돈사·우사 등 축사 | 농장 분기 후보 |
| 인간 | 먹이망의 단순 최상위가 아니라 여러 생태 경로가 합쳐지는 최종 생활권 | 주택, 병원, 연구소 | 후반 최종 후보 |

`포식성 조류`는 부엉이·올빼미·매류 중 맵과 톤에 맞는 종으로 추후 확정한다. 쥐보다 아래에 놓이는 일반적인 `새` 한 종류로 통합하지 않는다.

## 전이 루트 구조

### 기본 전이 유형

| 유형 | 게임 내 사건 예시 | 경로 성격 |
| --- | --- | --- |
| 포식 전이 | 쥐가 곤충을 먹거나 포식성 조류가 쥐를 사냥 | 먹이사슬 상승을 가장 직접적으로 표현 |
| 섭취 전이 | 오염된 물·먹이·사료를 다른 동물이 섭취 | 포식 관계가 없는 숙주 사이를 연결 |
| 접촉 전이 | 상처, 침, 털, 배설물, 오염 표면과 접촉 | 반려동물·야생동물·인간 생활권 연결 |
| 환경 전이 | 배수관, 하천, 쓰레기, 운반 상자와 함께 이동 | 거시 숙주 없이 감염 세균·오염수와 함께 맵 사이를 잇는 제한적 이동 |
| 인간 매개 전이 | 사육, 구조, 진료, 운반, 연구 과정에서 이동 | 포식성 조류·반려동물·가축에서 인간으로 연결 |

### 대표 루트 후보

대표 진행은 하나의 고정 사슬보다 여러 경로가 인간 생활권에서 합류하는 구조로 둔다.

```text
곤충 → 쥐 → 포식성 조류 ─┐
  ├→ 닭·소형 조류 ───────┤
  └→ 가축 ────────────────┼→ 인간 → 병원 → 연구소
쥐 → 고양이·개 ──────────┤
환경수·오염 먹이 ─────────┘
```

- `곤충 → 쥐 → 포식성 조류`는 먹이사슬 상승을 가장 선명하게 보여주는 대표 생태 루트다.
- `쥐 → 고양이·개 → 인간`은 도시 생활권과 반려동물 접촉을 강조하는 루트다.
- `곤충·환경 → 닭·가축 → 인간`은 농장과 사육·먹이 경로를 강조한다.
- 포식성 조류에서 인간으로의 이동은 인간이 조류를 먹는 구조가 아니라 구조·진료·연구 또는 오염된 장비 접촉 같은 인간 매개 전이로 처리한다.

모든 경로를 한 번의 플레이에서 필수로 거치게 하지 않는다. 정식 캠페인에서 필수 숙주와 선택 숙주의 수는 로그라이크 구조와 한 런 길이를 정한 뒤 확정한다.

## 이전 맵 복귀 규칙

### 원칙

이전 지역은 폐기되지 않는다. 다음 지역군을 연 뒤에도 발견한 연결 경로를 통해 돌아갈 수 있다. 다만 `맵 해금`과 `현재 숙주가 실제로 통과할 수 있음`은 별개의 조건이다.

1. 같은 지역군의 인접 맵은 기본적으로 왕복 가능하다.
2. 지역군 사이의 경로는 전이 접점을 발견하거나 사건을 완료하면 해금된다.
3. 해금된 이전 맵도 현재 숙주의 크기, 이동 방식, 생활권 적합성에 따라 진입이 제한될 수 있다.
4. 현재 숙주가 통과하지 못하는 경우, 호환되는 숙주로 다시 전이하거나 환경 이동 경로를 찾아야 한다.
5. 포식 전이로 이전 개체를 잃었더라도 이전 `맵`은 사라지지 않는다. 단, 같은 개체로 되돌아가는 것은 아니다.
6. 방역·격리·홍수·화재 같은 서사 사건은 경로를 일시 차단할 수 있지만, 기본 설계에서는 사전 경고 없는 영구 미스를 만들지 않는다.

### 예시

- 쥐는 하수도 본관, 배수관, 지하 창고를 자유롭게 오갈 수 있다.
- 포식성 조류로 전이한 뒤에는 공원·옥상·농경지 상공으로 돌아갈 수 있지만, 좁은 배수관에는 직접 들어갈 수 없다.
- 플레이어가 하수도에 다시 들어가려면 쥐나 다른 소형 숙주로 전이하거나, 오염수 이동 같은 별도 경로를 열어야 한다.
- 고양이는 골목과 주택가를 쉽게 오가지만, 축사 내부나 깊은 하수도에는 특정 접점 없이 진입할 수 없다.

## 플레이 흐름

1. 현재 숙주의 생활권 맵을 탐색한다.
2. 먹이, 포식자, 물, 배설물, 인간 접촉 같은 전이 접점을 발견한다.
3. 다음 숙주 후보와 도착 맵을 미리 확인한다.
4. 전이 조건을 충족하고 내부 바이러스·면역 구간을 통과한다.
5. 새 숙주의 이동 방식과 고유 특성으로 새 지역을 탐색한다.
6. 이전에 잠겨 있던 길을 열거나, 이전 지역으로 돌아가 놓친 자원·숙주·전이 경로를 찾는다.
7. 여러 생태 루트 중 하나를 통해 인간 생활권과 후반 통제 구역에 도달한다.

전이 선택 화면에는 최소한 `다음 숙주`, `도착 생활권`, `전이 유형`, `되돌아올 수 있는 예상 경로`를 보여준다. 플레이어가 숙주 선택으로 잃는 접근 권한을 모른 채 진행하지 않도록 한다.

## 숙주 경험 특성과 맵 루트의 관계

숙주 경험 특성은 이전 숙주의 신체 능력을 그대로 복제하지 않고, 다른 숙주에서도 경로를 발견하거나 위험을 완화하는 방식으로 사용한다.

- 쥐의 `좁은 틈 감각`: 큰 숙주가 배관을 통과하는 능력이 아니라 작은 우회·전이 접점을 감지한다.
- 포식성 조류의 `고공 시야`: 이미 방문한 지역의 숨은 연결부나 이동 중인 숙주를 표시한다.
- 반려동물의 `인간 친화`: 주택·진료 공간의 인간 접촉 경로를 안정적으로 연다.
- 가축의 `사육 환경 적응`: 사료·급수·운반 설비를 통한 환경 경로의 위험을 낮춘다.

이 특성들은 장기 캠페인 제안이며 현재 쥐 프로토타입에는 자동 추가하지 않는다.

## 실패와 막힘 방지 원칙

- 현재 숙주로 갈 수 있는 전이 접점이 최소 하나는 항상 남아 있어야 한다.
- 특정 숙주를 선택해도 캠페인이 영구적으로 막히지 않아야 한다.
- 접근 권한을 잃는 전이에는 사전 경고를 제공한다.
- 이전 지역 복귀가 당장 불가능하면 필요한 숙주 또는 우회 조건을 지도에 표시한다.
- 선택 숙주를 놓쳤더라도 다른 루트로 인간 생활권에 도달할 수 있어야 한다.
- 생물학적 설명과 게임 규칙이 충돌하면 `현실 기반의 게임적 각색`임을 도감이나 전이 설명에 표시한다.

## 현재 확정과 미확정

### 이번 문서에서 확정하는 설계 원칙

- 혼합형 먹이망·감염 경로를 사용한다.
- 숙주와 서식지 맵, 전이 접점을 하나의 월드 그래프로 설계한다.
- 지역군 내부 왕복과 조건부 이전 지역 복귀를 허용한다.
- 현재 숙주의 생태와 이동 능력이 실제 사용 가능한 맵 경로를 결정한다.
- 포식성 조류는 쥐보다 상위 먹이사슬에 둔다.
- 인간은 단일 포식 사슬의 끝이 아니라 여러 생태·생활권 경로가 합쳐지는 최종 단계로 둔다.

### 후속 승인 전 미확정

- 정식 첫 숙주와 필수 숙주 수
- 포식성 조류·가축·곤충의 정확한 종
- 각 지역군의 실제 맵 수와 크기
- 한 런에서 방문 가능한 분기 수와 영구 해금 범위
- 환경 전이 중 바이러스를 직접 조작하는 별도 모드의 유무
- 인간 숙주의 직접 조종 범위
- 병원·연구소·백신·엔딩의 세부 규칙

## 승인 경계

- 이 문서를 근거로 전체 숙주 체인, 신규 맵, 인간 단계, 병원, 연구소를 Unity에 구현하지 않는다.
- 현재 승인된 쥐 숙주 프로토타입은 작은 하수도 맵의 단일 수직 슬라이스로 유지한다.
- 다음 구현 단계에서는 이 문서 전체가 아니라 `숙주 1종 + 지역군 1개 + 전이 접점 1개` 단위로 별도 승인받는다.
