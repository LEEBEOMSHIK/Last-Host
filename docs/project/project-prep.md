# The Last Host 프로젝트 준비안

최종 수정일: 2026-07-27

## 목적

이 문서는 `마지막 숙주 / The Last Host`의 구현을 시작하기 전에 현재 준비 상태를 정리하기 위한 문서다. 확정된 방향, 승인 상태, 저장소 상태, Unity 프로젝트로 전환하기 전 필요한 순서를 정리한다.

## 현재 저장소 상태

- 작업 위치: `C:\project\Last-Host`
- Git 원격 저장소: `https://github.com/LEEBEOMSHIK/Last-Host.git`
- Unity 프로젝트 루트: `UnityProject/`
- Unity 버전: `6000.4.6f1`
- 렌더 파이프라인: URP 패키지 포함
- 현재 단계는 Unity 프로젝트 골격을 루트 저장소에 편입하고 프로토타입 구현 전 준비를 정리하는 단계다.

## 원본 기획 자료

- 원본 초안: `C:\project\game\last_host\last_host_game_plan.docx`
- 초안의 핵심 방향은 도트풍 저폴리 3D 진화 생존 로그라이크였다. 2026-07-16에는 이를 3D 원본 기반 캐릭터 스프라이트를 결합한 하이브리드 2.5D로 구체화했으나, 2026-07-27 사용자 승인으로 현재 작업 해석본은 2D 아이소메트릭 도트 방식으로 전환되었다.
- 초안은 핵심 루프 검증을 위해 `쥐 숙주 프로토타입`부터 시작하는 방향을 제안한다.

## 확정된 결정

- 엔진: Unity
- 비주얼: 2D 아이소메트릭/쿼터뷰 도트
- 렌더링 방향:
  - 환경과 이동 공간은 반복 가능한 2D 아이소메트릭 타일로 구성
  - 쥐·바이러스·백혈구와 효과는 방향별 2D 도트 스프라이트로 표시
  - 고정 아이소메트릭/쿼터뷰 카메라, 2D 충돌 영역, 가림과 Y축 깊이 정렬 사용
  - 동일한 픽셀 밀도, 외곽선, 명암 방향과 제한 팔레트 유지
- 게임 구조:
  - 바깥 세계의 숙주 조종 탐험
  - 숙주 내부의 바이러스 면역 미니게임
  - 변이 선택과 성장
- 첫 프로토타입 초점: 하수도 환경의 쥐 숙주
- 쥐는 벌레보다 상위 숙주지만, 첫 프로토타입에서는 정식 진행 순서가 아니라 핵심 루프 검증용 수직 슬라이스로 사용한다.
- 1차 프로토타입에는 벌레 튜토리얼을 포함하지 않는다.
- `docs/design/visual/references/rat-host-2d-isometric-gameplay-mockup-v1.png`는 목표 분위기·구도 reference이며, 실제 타일셋·스프라이트 시트·애니메이션 또는 최종 게임 에셋이 아니다.
- 기존 3D 환경·저폴리 원본·Blender 프리렌더 파이프라인은 신규 제작의 기본 경로에서 제외하고 승인 이력과 비교를 위한 레거시로 보존한다.
- 목업·콘셉트·스프라이트 초안은 ChatGPT 내장 이미지 생성과 연계할 수 있다. 프롬프트와 생성물을 기록하고, 사람 선별과 게임 규격 재제작·QA를 거친 뒤에만 실제 에셋 후보가 된다.

## 구현 승인 상태

2026-06-30 기준, 사용자가 쥐 숙주 1차 프로토타입 구현에 필요한 항목을 전체 승인했다.

1. Unity 버전
2. URP 사용 여부
3. PC 우선 프로토타입 확정 여부
4. 첫 프로토타입의 성공과 실패 조건
5. 초기 조작 방식
6. 초기 UI 게이지 구성
7. 플레이스홀더 에셋 사용 범위
8. 프로토타입 변이 효과

승인 이력은 `docs/prototype/approvals/rat-host-approval-packet.md`에 정리한다.

참고: 현재 Unity 프로젝트는 `UnityProject/`에 편입되어 있으며, 1차 프로토타입은 Unity `6000.4.6f1`과 URP를 기준으로 진행한다.

## 권장 마일스톤

### 마일스톤 0: 준비

- 기획서 초안을 작업용 Markdown 문서로 정리한다.
- 엔진, 비주얼 방향, 프로토타입 범위, 승인 게이트를 확정한다.
- Unity 버전과 렌더 파이프라인을 결정한다.

### 마일스톤 1: Unity 프로젝트 골격

- Unity 프로젝트 골격을 `UnityProject/`에서 관리한다.
- 저장소 정리, `.gitignore`, 기본 폴더, 렌더 파이프라인 설정을 확인한다.
- 2D 아이소메트릭 타일맵과 고정 카메라가 있는 최소 테스트 씬을 만든다.

### 마일스톤 2: 쥐 숙주 핵심 루프

- 작은 하수도 맵에서 쥐를 움직인다.
- 면역 경계도 게이지를 적용한다.
- 내부 바이러스 미니게임으로 전환한다.
- 바이러스 이동, 백혈구 적, 변이 조각 수집을 구현한다.
- 변이 선택 후 쥐 숙주 모드로 복귀한다.

### 마일스톤 3: 프로토타입 감각 조정

- 2D 아이소메트릭 도트 타일과 방향별 캐릭터 스프라이트를 조정한다.
- 카메라 추적, 충돌, 가림과 Y축 깊이 정렬을 다듬는다.
- 기본 UI 가독성을 확인한다.
- 플레이스홀더 애니메이션과 피드백을 추가한다.
- 짧은 플레이테스트 체크리스트로 핵심 루프를 검증한다.

## 바로 다음 단계

1. 2D 아이소메트릭 전환 작업 패킷과 기술 샘플 수용 기준을 확정한다.
2. 작은 하수도 방 1개, 반복 타일, 쥐 정지·보행 방향 스프라이트, 카메라, 충돌, 가림·깊이 정렬을 별도 샘플로 구현한다.
3. 실제 플레이 해상도와 Windows 빌드에서 목업의 분위기·캐릭터 가독성·조작 정합을 비교한다.
4. 기술 샘플이 승인되면 기존 핵심 루프를 2D 구조로 단계적으로 이관하고 회귀 검증한다.
