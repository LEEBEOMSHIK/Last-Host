# Pixel Lowpoly Style Keeper

## 이름과 현재 역할

스킬 이름은 기존 작업·호출 호환성을 위해 유지한다. 현재 기준은 저폴리 2.5D가 아니라 2026-07-27 승인된 `2D 아이소메트릭 도트`다.

`마지막 숙주 / The Last Host`의 환경은 2D 아이소메트릭 타일과 소품, 캐릭터·효과는 방향·상태별 2D 스프라이트로 제작한다. 기존 3D 환경·저폴리 원본·Blender 8방향 프리렌더는 레거시 이력으로만 다룬다.

## 비주얼 원칙

- 고정 아이소메트릭 또는 쿼터뷰 화면을 사용한다.
- 환경은 공통 격자와 투시를 가진 반복 타일·소품 스프라이트로 구성한다.
- 캐릭터는 같은 체형·무늬·피벗·화면 점유율을 유지하는 방향·상태별 2D 스프라이트로 제작한다.
- 자연형 쥐의 등–목–머리 곡선, 발 접지, 귀·코·꼬리의 읽힘을 우선한다.
- 환경·캐릭터·효과의 논리 픽셀 크기, 명암 방향, 색 밀도를 맞춘다.
- 플레이어·위험·수집물·이동 경로가 장식보다 먼저 읽혀야 한다.
- 앞뒤 정렬은 발 접지점 또는 명시적 레이어를 기준으로 하며 가림을 실제 이동에서 검증한다.
- HUD·텍스트는 월드 픽셀 출력과 분리해 선명하게 유지할 수 있다.

## ChatGPT 이미지 경계

- OpenAI 내장 `imagegen`은 목표 화면, 외형 콘셉트, 타일·소품·UI 탐색 후보에 사용할 수 있다.
- 프로젝트 reference와 승인된 브리프를 사용한다.
- 프롬프트, 도구, 날짜, 입력 출처, 출력 경로와 선별 결과를 기록한다.
- 생성 결과는 실제 타일셋·스프라이트 시트·애니메이션으로 자동 승인하지 않는다.
- 방향별 AI 결과는 체형·투시·팔레트·피벗 일관성을 대조하고 사람이 게임 규격으로 재제작·보정한다.

## 작업 절차

1. 요청이 캐릭터, 환경 타일, 효과, 카메라·정렬, 픽셀 출력, UI, 이미지 후보 중 어디에 속하는지 분류한다.
2. 목업·후보와 실제 게임 에셋을 구분한다.
3. 타일 반복, 캐릭터 방향·프레임, 공통 피벗, 앞뒤 정렬과 픽셀 출력을 함께 검토한다.
4. 플레이스홀더와 최종 아트 요구를 구분한다.
5. 기존 2.5D 자료가 필요하면 레거시 문서임을 명시한다.
6. 실제 생성·Unity 적용·규격 승격에 필요한 승인을 분리한다.

## 금지 범위

- 사용자 승인 없는 실제 에셋 생성
- 목업 또는 AI 후보를 최종 타일·스프라이트로 선언
- 방향별 AI 프레임을 일관성 검토 없이 최종 시트로 사용
- 신규 2D 제작의 기본 경로를 승인 없이 Blender 프리렌더로 되돌림
- 프로토타입 범위 밖 콘텐츠 추가
